# ATANOR 진짜 이해 로드맵 — 정의-구토를 능력으로 (2026-07-20)

사장님 질문 3: ① 왜 정의를 내뱉나 ② 말하기 전 맥락 검토가 없나 ③ 애초에 이해할 지능이 없나.
지시: **테스트에 맞춘 야메 금지 — 능력이 진짜로 자라서 통과하게.**

## 0. 정직한 진단 (측정 기반)

이번 세션 사장님 시험 전부가 **같은 방식으로** 실패했다:
| 시험 | ATANOR 출력 | 기전 |
|---|---|---|
| 미지 동역학 600라운드 제어 | "Its is a possessive determiner…" | 지문 속 부수어 "its"를 base_brain 키워드 레인이 포획 |
| Black Relay 포렌식 (283M 가설) | 지문 되뱉기 | personal-recall 레인이 컨텍스트를 "개인 사실"로 오인 |
| 세계-내-자기 인과 | 에러/되뱉기 | 상동 |
| (앞서) 토론 턴 | "Risk is a board game" | 상동 |

**공통 뿌리 하나**: 입력이 어떤 레인의 의도 패턴에도 안 맞으면, 엔진은 "이해 실패를 인지"하는 대신
**"아무 키워드나 잡아 아는 것을 말한다"**. 즉,
- ①의 답: 최종 폴백 = 키워드 인출이라서. (기권근절을 "항상 인출"로 구현한 부작용)
- ②의 답: 검토 조각들(자기의심·메타인지·web relevance)이 **레인별 후처리**로만 존재 — "후보 답이 질문에
  실제로 응하는가"를 **모든 답에** 묻는 보편 관문 부재.
- ③의 답: **예 — 낯선 텍스트→상황모델 기관이 부재**(고장 아님, 부재). 의도분류+개체+그래프 인출이
  이해의 전부이며, 신규 구조 지문(규칙·역할·제약·요구형식)을 모델링하는 기관이 없다.

## 1. 진짜 능력의 요구 스택 (시험들이 공통으로 요구하는 것)

```
L1 이해   : 낯선 지문 → 상황모델(개체·역할·규칙·제약·"무엇을 요구하는가"·요구 형식)
L2 자기   : 이 상황이 나에게 요구하는 응답 종류의 인지 (JSON-only / WITHDRAW / 자기-인과 서술)
L3 추론   : 상황모델 위 연산 (제약전파·가설소거·인식논리·시스템식별-제어·자기-반사실)
L4 정직   : L1~L3가 감당 못 하면 확신 없는 발화 대신 철회(WITHDRAW) — 봉인시험 자체가 이걸 보상
```

## 2. 성장 사다리 A→D (전부 일반 기관 — 시험 정답 맞춤 아님)

### A. 보편 발화-적합 관문 (오늘 실행) — "말하기 전 검토"의 실체
단일 출구(답이 나가는 그 지점)에서 **모든** 후보 답에 대해: 답의 앵커가 질문의 **부수 기능어**인가?
질문의 내용어 초점과 답의 내용이 **겹치는가**? 강한 불일치면 발화하지 않고 **정직한 이해-한계 응답**
("나는 이것을 X로 읽었다; X를 신뢰 있게 수행 못 하므로 추측하지 않는다").
- 이는 21번째 모드스위치가 아니라 **voice-or-silence 헌법의 전역 시행**. 매 요청 실행, 무관하면 통과.
- 주의: 이해를 더하진 않는다. **비이해의 자기인지**를 더한다 — 사장님 ②가 요구한 그 기관.
- 부수 효과(야메 아님): Black Relay는 스스로 "certify 불가면 WITHDRAW가 정답"이라 명시 — 관문만으로
  "0점+망신"에서 "시험이 정의한 정직 응답"으로 이동.

### B. 상황모델 빌더 v0 (이해 기관) — 형식/구조 지문 우선
문장 수준 의미틀 추출기를 **문서 수준**으로 확장: 개체·역할·수량화 규칙·제약·요구(ask)·응답 형식 계약
(JSON-only, 금지사항, WITHDRAW 옵션)을 뽑아 작업 모델로. 형식 지문(시험·스펙·규칙)은 자유 산문보다
No-LLM으로 **더** 다루기 쉽다(문법 주도 파싱). 게이트: 사장님 시험 3종에서 ask+형식계약 추출 정확도.

### C. 상황모델 → 실제 해결기 디스패치 (기존 기관 재사용 + 2 신설)
이미 보유: reasoning VM(술어대수)·DELIBERATOR(후방연쇄)·ARC 합성(프로그램탐색+검증)·block_universe(인과).
신설 2: ① **가설소거 엔진**(Black-Relay류: 세계×오류셋을 월드당 비트셋으로 — 9!×C(40,2)는 33MB급, 순수
계산으로 진짜 풀림 — AlphaGeometry 노선 그대로) ② **시스템식별+안전제어 엔진**(600라운드류: 진단행동→
모델적합→불확실성 예측 — 고전 공학, No-LLM 정공법).
클래스를 푸는 일반 엔진이지 인스턴스 정답키가 아님 — digest 봉인 시험을 정당하게 통과하는 길.

### D. 자기=인과노드 합성 (세계-내-자기 통과)
상황모델에 "You"(응답자)가 등장하면 자기모델에 바인딩, block_universe의 반사실 연산을 자기 사슬
[판단→출력→채널→세계]에 적용. 부품(타임라인 자기사건·자서전·인과투영)은 있고 **합성만 부재**.

## 3. 게이트 (사전선언)
- G-A: 사장님 시험 3종 재실행 → 정의-구토 0, 정직-한계 응답으로 대체 **AND** 사실 QA 배터리 무회귀.
- G-B: 시험 지문에서 ask/형식계약 추출 — 사람 채점 일치.
- G-C1: Black-Relay류 합성 인스턴스(우리가 생성·자체채점)에서 유일해 복원.
- G-C2: 시뮬 동역학 환경에서 안전구간 유지율+예측오차 — 명시 벤치.
- G-D: 세계-내-자기 프로브 PASS (기존 채점기, GPT 3.5와 동급 목표).

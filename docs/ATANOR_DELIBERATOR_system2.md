# DELIBERATOR — ATANOR 숙고 회로 (System-2 다단계 추론기) 설계 v1.0

**승인 맥락**: 사장님 2026-07-16, GPQA급 다단계 추론 회로 설계 지시. GPQA 오픈북 실측 0.146(<추측
0.25)의 원인 진단("사서는 완벽, 수험생 논리력 부재")에 대한 아키텍처 응답.

## 0. 핵심 원리 — 질문 생성은 생성이 아니라 계산이다
No-LLM 플래닝의 열쇠 = **후방 연쇄(backward chaining)**: 목표를 규칙에 거꾸로 대면 미충족 전제가
곧 다음 검색 질의다. (목표 "전이 X의 에너지" → E=hc/λ → λ 미지 → 질의 "λ of X".) 증명 탐색이
사고사슬이고, 증명의 구멍이 사서에게 보낼 쪽지다. LLM 자유생성 불필요.

## 1. 7기관 회로
① **목표 컴파일러** — ACE 태깅 헤드: 묻는-양/개체·조건·제약 → 타입드 목표 그래프; 보기 4개도
   후보 배정으로 컴파일. (훈련: HotpotQA/MuSiQue 분해·근거 주석, GSM8K 체인 — 공개 train만)
② **후방 연쇄 계획기** — 작업기억=유도 그래프(노드=명제/양, 엣지=규칙+출처), 깊이≤4 빔~8.
   전제 편입 조건: KG-검증 ∨ ACE-support≥문턱 ∨ 정확커널 유도 → **환각0 구조 보존**.
   씨앗 = 기존 멀티홉 합성대수(75% 환각0 SHIPPED).
③ **반복 사서** — 하위질의는 술어+개체 템플릿 조립(자유생성 아님) + search orchestration v2 재사용.
④ **ACE 판독기 (D0)** — support/NLI 헤드 훈련: FEVER(주장+위키근거→지지/반박/불충분), SciTail,
   SciQ. 스팬 헤드로 값 추출 + 양 정규화.
⑤ **규칙·수식 기지 (신규 수확 레인)** — 7M 패시지에서 수식·상수·단위관계 채굴 → 합의 게이트 →
   타입드 규칙 등재. 실행=정확 커널(arithmetic/quantity)+단위 대수. 새 유도 커널 필요 시
   **VibeCode**(검증기-유도 합성)가 조립 담당.
⑥ **보기 판정기** — 각 보기 유도 시도 + 반박 시도(유도 제약과 모순=소거). 점수 = 유도 완결도 ×
   최약 엣지 신뢰도. 시험모드 무기권+신뢰도 표기(기권0 독트린).
⑦ **검증·영수증** — 전 스텝 출처 동봉, 기존 reasoning certificate 재사용.

**상부 자기개선층**: 실패 법의학(기관별 오라클-갭 = RIF 프로버 방법론) → 미스-커리큘럼 →
해당 기관 재훈련/기지 확장. RIF=판독기 표현 발명, VibeCode=커널 합성.

## 2. 왜 구조적 천장이 없는가 (특이점 도달 가능성의 정직한 정의)
- 능력 = 규칙·수식 기지(수확으로 성장) × 판독기(데이터로 성장; M1 AUC 0.52→0.816이 증명) ×
  연쇄 깊이(연산으로 성장) — 셋 다 독립 개선 가능.
- 유도 체인이 명시적 → 모든 오답이 기관·엣지 단위로 귀속 → 커리큘럼 → 재측정 (폐루프).
- LLM 대비: 그들의 사고사슬은 검증불가 자유텍스트(깊을수록 환각 누적), 우리는 전 스텝 체커블
  (깊을수록 인증서 누적).

## 3. 정직한 한계 (사전 선언 — 만점 약속 금지)
GPQA Diamond: 전문가 ~65%, GPT-4 ~39%, 웹 허용 비전문가 ~34%. 대학원급 절차지식(반응 메커니즘,
분광 휴리스틱)은 수식 채굴로 전부 안 잡힘. GPQA는 봉인 유지(훈련 금지, 계량기로만).

## 4. 사다리 게이트
| 단계 | 내용 | 게이트 |
|---|---|---|
| D0 | ACE support 헤드 (FEVER+SciTail) | 지지판별 val acc 다수결 유의 초과 |
| D1 | 단일홉 판정기 (ARC/SciQ, ACE-support를 openbook 하네스에) | ARC-easy test ≥ 0.45 |
| D2 | 양·수식 레인 (채굴 10만 + 정확커널) | 단위대수 100% + GSM8K-lite 해결율 보고 |
| D3 | 후방 연쇄 멀티홉 (HotpotQA/MuSiQue) | 근거문 F1 + answer EM 실측 |
| D4 | 전 회로 → GPQA Diamond | 1차 = 추측 0.25 초과(현재 0.146) → 2차 = 0.34 → 이후 실측이 말함 |

## 5. 착수 순서
ACE v2b 완료 → D0 support 헤드(같은 본체+FEVER, ~1일) → D1 아레나(vs GBM 스코어러) → D2 수식
채굴 레인 → D3 후방 연쇄 → D4 봉인 계측.

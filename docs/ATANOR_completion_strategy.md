## 장기(臟器) — 4 조직 (전부 기존 부품 재배치)
- **D1 수면 통합 데몬**: 라이브기억+미스 재생 → 검증분 그래프 승격(해마→피질) → 미스에서 커리큘럼 채굴 →
  TCT 사이클 → 봉인 배터리=적합도 → 이길 때만 배포. "자고 나면 똑똑해짐"의 공학판. **최우선(최대 레버, 배선 위주).**
- **D2 S1/S2 라우터**: 기본 빠른 연상, 접지신뢰 낮거나 증거충돌 때만 DELIBERATOR 승격. 20W 효율의 절반.
- **D3 호기심 폐쇄**: 기권·저신뢰·미스 → 자동 바운디드 웹 원정 → 수확이 D1로.
- **Stage2 진화 아레나**: 5-변이체 화자 아레나를 헤드/정책 전반으로 일반화. 봉인 적합도 개체군 경쟁.
- **Stage3(프런티어, ETA 없음)**: 봉투-벽 법의학 → 에이전트가 새 기관 스펙 초안 → 병합만 인간 서명.

## "인터넷에 풀어 진화" — 되게 하는 불변식 6 (면역계 있는 진화)
①얼린 신탁 적합도(wireheading 차단) ②격리→검증→승격(오염 차단) ③주입/PII/정크 게이트(적대 차단)
④출처 100% ⑤로직 자기수정=인간 게이트 ⑥킬스위치+자원 캡.
→ 이게 있어서 "풀어도 되는" 상태. 지식 자율성장=지금 됨 · 스킬=게이트 뒤 수면 사이클당 한 계단 · 기관발명=연구.

## 착공 순서
D1(수면통합) → D3(호기심) → D2(라우터) → Stage2(아레나). 기존 자산 하나도 안 버림.
규율: 버저닝(v2 회귀서 원본보존 증명) · 이길 때만 배포 · 워치독 하 서비스 · 속도변경 후 웜배터리 · 정직 ETA(약속은 게이트 통과 속도까지만).

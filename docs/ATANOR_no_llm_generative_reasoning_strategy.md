# ATANOR No-LLM 생성 추론 전략 (B-노선: 둘 다)

> 사장님 지시 (2026-07-16): "둘 다로 할 방안을 내. 생성 추론을 원래 하기로 했었잖아. B로 가. No LLM으로 가능하게."
> 규율: measure-don't-claim. 게이트 통과 전 등급 상승 주장 금지. 봉인 홀드아웃으로만 측정.

## 0. 존재 증명

**AlphaGeometry (Trinh et al., Nature 2024)**: 사전학습 LLM 0, 인간 시연 0.
151M 소형 트랜스포머를 **1억 개 합성 정리+증명으로 밑바닥 훈련** + 심볼릭 추론엔진(DD+AR) 결합
→ IMO 기하 25/30 (금메달리스트급). **공식 = 합성 유도 공장 + 검증기 + 소형 안내모델 + 심볼릭 탐색.**

ACE2 실패(AUC 0.527)의 교훈 재해석: 실패한 건 "일반 언어 사전학습을 소규모로 흉내"낸 것.
AlphaGeometry는 일반 언어를 배우지 않았다 — **좁은 유도 과제 + 무한 합성 데이터**를 배웠다.
우리 자체 씨앗: ace_squad answerability **val AUC 0.8275** (2026-07-16) — 좁은 판별 과제는
우리 규모 from-scratch로 학습됨(측정). LM 이전 Aristo(2016) IR+PMI+추론 앙상블 = 초·중등
과학 MCQ 60~70%대 — MCQ 판별은 사전학습 LM 없이 우연을 크게 넘긴 전례가 있다.

## 1. 원리: LLM 3능력의 분해 대체

| LLM 능력 | LLM 구현 | ATANOR No-LLM 대체 |
|---|---|---|
| 세계지식 소환 | 수천억 파라미터 암기 | **디스크가 파라미터**: 로컬 팩(kg_triples 26.9M + world_pack 141.7M + 패시지 685k). 오픈북=우리의 클로즈드북(무인터넷, 같은 제품 표면) |
| 다단계 추론 | 암묵적 CoT | **명시적 유도 탐색**: 후방연쇄(DELIBERATOR) + 검증 커널(KernelForge) + 유추(LeapEngine) + 뇌형 그래프(인식 사다리). 소형 from-scratch 모델이 탐색 안내 |
| 유창한 생성 | 다음토큰 샘플링 | **DERIVE→REALIZE**: 유도 트리 매 스텝을 실현기(구성문법+담화전이+holographic)가 문장화. CoT=감사 가능(스텝=그래프 엣지 or 커널) |

벤치는 오픈북 리그로 정면 승부하고 헤드라인에 명시한다.

## 3. 레인별 설계

### L1 — MCQ 판별기
2026-07-16 측정 결과로 레버 우선순위 수정:
1. ~~**PMI 통계 솔버**~~ **기각(측정)**: 프루닝 인덱스판 n=40서 baseline(0.265)→0.125 회귀; 온전-어휘
   PMISolver 재구축 후 프로브도 **1/8**(mitochondria 등 0.0). 근본원인 = (a) 패시지가 위키 **리드 문단만**
   이라 공출현 희박, (b) **공출현≠정답성**('nucleus'가 'cell'과 더 자주 나오나 답은 'mitochondria').
   마진 게이트가 5/8 기권해 정직하나 정확도를 더하지 못함. → 플래그 OFF(ATANOR_PMI), 회귀 미배포.
2. ~~**선택지-조건 검색**~~ **기각(측정)**: n=40서 0.167<0.2. (질문+선택지) top-k가 느슨히 관련될 뿐
   정답보유 아님이 많음. 플래그 OFF(ATANOR_OC).
3. **★함의 판정기(from-scratch) = 진짜 레버**: (Q, passage, option)→entail 확률. ACE 아키(27M)
   크로스인코더를 **원거리 감독 데이터 공장**으로 훈련: 참 트리플→긍정, **같은 술어의 형제 엔티티
   =타입일치 하드네거**. 근거: answerability 헤드가 우리 규모 from-scratch로 val AUC 0.8275 도달(측정)
   = 좁은 판별은 학습됨. 통계 해킹(PMI)이 아니라 **학습된 판정기**가 길. LLM 교사 0.
   - 중단 규칙: 판정기 val AUC 0.6대 정체면 보고·중단(ACE2 교훈).
4. **정밀도 우선 재랭킹**: 이미 openbook path가 title 검색 성공 문항서 0.375. 개선 초점 = 판정기로
   `_entail_score` 대체(정밀) + 검색 리콜(더 많은 문항서 옳은 패시지). 앙상블 → 봉인 홀드아웃.

**측정 교훈(BINDING, 2026-07-16 4레버 사망)**:
- PMI 통계 0.125·선택지-조건 검색 0.167·**밑바닥 (Q,option) 판정기** 모두 기각.
- 판정기는 그래프 하드네거로 학습·성장(0.43→0.48 in-dist)했으나 **실벤치 전이 0**: MMLU 0.255, CSQA 0.186
  (ConceptNet 태생 벤치조차 우연). = **합성 템플릿의 인공물을 학습**한 것. in-dist 0.48은 착시.
- ★근본: **클로즈드북((Q,option), 무패시지)은 원리적으로 불가** — 지식이 27M 가중치에 없음(물리).
  합성 MCQ 판정기는 자기 분포의 표면통계에 과적합. **오픈북(검색→패시지→함의)만이 유일한 길.**
- 남은 병목 = **검색 정밀도**(옳은 패시지 찾기; 현재 title 4/200, content 38%지만 오답 패시지) +
  **코퍼스 깊이**(위키 리드문단 vs 교과서 사실). 값싼 지름길 재시도 금지 — 이건 진짜 IR+훈련 노력.
- ★전략 재조정: L1(지식 MCQ)은 No-LLM에 가장 불리(지식-바운드). **L2(수리=결정론 풀이)·L4(생성=체감)가
  No-LLM 구조적 우위** — 수학은 검색 아니라 파싱+커널 실행으로 '푼다'(AlphaGeometry 본령). 여기로 무게 이동 검토.

### L2 — 수리 유도 (AlphaGeometry 노선)
1. **합성 문제 공장**: 커널(단위대수·비율·%·속도·화학량론)을 역으로 돌려 무한 워드프러블럼+정답 유도 생성.
2. **파서**: 질문→수량/관계 스키마. from-scratch 인코더+슬롯 디코더, 합성 데이터로 훈련.
3. **실행**: 커널 체이닝(KernelForge 획득 커널) + 후방연쇄. 산술은 계산기 정확도.
4. GSM8K 봉인 홀드아웃. 파싱 실패는 정직히 UNKNOWN(찍기 없음, 시험모드는 coverage 1.0 + 신뢰도).

### L3 — 과학 유도
L1 판별 + L2 커널 + 뇌형 그래프 후방연쇄 결합. 화학/물리의 공식 적용형부터.
GPQA는 랜덤 탈출(>0.25)이 1차 게이트 — 지금은 랜덤 미만이라 "찍는 것보다 못함"이 현실.

### L4 — 유도-생성 (제품 체감)
1. DELIBERATOR가 뇌형 그래프+커널+유추로 **유도 트리** 생성(스텝별 인식 등급 부착).
2. 실현기가 트리를 다문장 답변으로 — "생각 과정"을 접을 수 있는 UI로 표시.
3. 측정: 문장별 접지 1.00(모든 문장이 트리 노드로 역추적) + 로컬 선호 평가(사장님/패널 블라인드 A/B).
4. 이 레인이 "GPT-Pro급 체감"의 정직한 승부처 — MCQ가 아니라.

## 4. 데이터 엔진 (연료)
- 그래프-구조 하드네거 MCQ 공장 (L1) — 즉시 가동 가능.
- 커널 역생성 수리 공장 (L2).
- 미스-커리큘럼 플라이휠(봉인 벤치 미스→다음 합성 타겟) — 기존 인프라 재사용.
- 장기: 웹 인테이크가 패시지 인덱스를 685k→수백만으로 성장.

## 5. 주장하지 않을 것
- 클로즈드북 암기 소환으로 GPT와 경쟁한다는 주장 (물리 불가).
- SWE-bench급 코드 에이전트 (스코프 밖).
- 게이트 통과 전 어떤 등급 상승 주장도. 뇌형 그래프의 환각0/ECE 해자를 희생하는 트레이드도 안 함.

## 6. 통과 시의 정당한 헤드라인
"**사전학습 LLM 제로** — 27M from-scratch + 로컬 지식팩으로 소형-LLM급 벤치 점수,
환각 0, 모든 답에 유도 경로." 이것이 '둘 다'의 실체다.

## 7. 실행 순서 (즉시)
1. L1-1/2: 오픈북 하니스에 선택지-조건 검색 + PMI 솔버 → 즉시 재측정 (일 단위)
2. L1-3: 하드네거 MCQ 데이터 공장 + 판정기 훈련 (주 단위)
3. L2: 합성 수리 공장 + 파서 v0 (주 단위)
4. L4: 유도트리→실현 배선 (뇌형 그래프 위, 주 단위)

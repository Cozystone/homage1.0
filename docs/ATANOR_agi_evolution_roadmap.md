# ATANOR AGI 진화 로드맵 — 철거 없는 단계적 장기 이식 (2026-07-18)

사장님 질문: "최종 목표는 AGI인데 가장 이상적인 AGI 구조로 가야 하지 않나? 갈아엎어야 하나?"
**판정: 갈아엎지 않는다.** 근거와 대체 계획이 이 문서다.

## 0. 전제 — "이상적 구조"는 알려져 있지 않다, 알려진 것은 속성이다

Type 6(뉴럴 기판 내 기호 창발)은 뇌가 증명한 **존재 증명**이지 공학 설계도가 아니다
(비행기는 날갯짓하지 않는다). 뇌 자체도 시스템 수준에서는 이질적 기억 기관들 + 지휘
구조(보완학습계) — 즉 우리가 지금 갖고 있는 Type 2/3 골격이다. 따라서 목표를 "구조
모방"에서 **"AGI가 요구하는 속성들을 게이트 통과로 하나씩 확보"**로 정의한다.
이건 기존 북극성(로컬 뇌형 범용)의 확장이지 전환이 아니다.

## 1. AGI 속성 대차대조표 (실측 기준)

| AGI 필요 속성 | ATANOR 현황 | 증거/게이트 |
|---|---|---|
| 지속 기억·망각 없는 축적 | **확보** (그래프 = 구조적 공짜) | Layer A 0.067→0.806, no-reset |
| 검증된 합성 추론 | **확보(1차)** | 멀티홉 2홉 900문항 1.0, 상속사다리 ECE 0.074 |
| 정직성·접지 | **확보** | fabrication 0, 접지 하드게이트 1.00 |
| 자기개선 (메타인지 루프) | **확보(바운드 명시)** | C5 플라이휠 +0.187, 사람라벨 0; 상한=교사 |
| 실세계 지각·신체 | **부분** | OWLv2 0.8s, 얼굴, 공간재생; SPLATRA 진행 |
| **유동적 직관·의미 매칭** | **최대 결손 — 병목 실측됨** | 어휘 천장 0.165, 소거 RED, ACE 0.52 벽 |
| 개방 생성(작문·코드·발명) | **결손 (정직한 벽)** | GSM8K 전이 0.019, 벽4 honest-null |
| 자율 목표·호기심 | 부분 | D3 호기심, 내발적 커리큘럼, 자기표적(E8 대기) |

**읽는 법: 결손 두 줄이 전부 "장기(의미 표현·생성)" 문제고, 확보 행이 전부 "골격"
소산이다.** 갈아엎으면 확보 행을 버리고 결손 행은 그대로 남는다.

## 2. 단계 계획 — 각 단계는 게이트 통과로만 진입 (rules-are-training-wheels의 전면화)

**Stage 1 — 의미 장기 이식 (지금 실행 중 = E9).**
27.9M 자체 인코더가 채점기 슬롯(재랭커·옵션-패시지 함의·concept_filter)을 채운다.
게이트(사전등록 완료): 서술형 오라클 0.165→≥0.30 + D1-SEM 신선 슬라이스. 소켓은 이미
출하됨(concept_filter, MultiHopReader ACE2 분기) — **이식 수술대는 차려져 있다.**

**Stage 2 — 장기의 확장과 다양화 (분기 단위).**
Stage 1이 green이면 같은 공정(전자동 합성쌍 + 사전등록 게이트)으로 장기를 늘린다:
스팬/함의 특화 헤드, 학습 라우터 고도화, GLL 직관 제안기(잠재대수)의 학습화, 지각
기관 통합 심화. **차터 경계 명시: 장기는 기술(skill)이다 — 지각·매칭·실현. 지식은
계속 그래프에 산다.** 자체 훈련이라도 "지식을 가중치에 넣는 대형 생성 모델"은 차터
위반으로 본다(그건 이름만 바꾼 LLM이다).

**Stage 3 — 지휘의 학습화 (기존 독트린의 완성).**
손규칙 오케스트레이션을 학습 라우터가 계승(37→75% 실증 공정의 전면 적용), C5
플라이휠을 전 슬롯에 연결, E8 자기표적 커널 → G1→G3 졸업 사다리. 여기까지가
"깊어진 Type 2/3" — 뇌의 시스템 수준과 동형이다.

**Stage 4 — 수렴 연구 지평 (Type 6 방향, 연구 트랙으로만).**
기호를 버리는 게 아니라 **이중화**한다: 감사 원장은 영원히 그래프(뿌리 권한), 그 위에
학습된 연속 공간(위상공간 확장, "임베딩 공간의 건전한 추론" — Tensor Logic 계열 리뷰
큐)이 **빠른 직관 경로**로 그래프를 미러링한다 — 신피질이 해마를 미러링하듯(CLS
유기체가 이미 이 구도의 배아). 승격 조건: 연속 경로의 답이 기호 경로와 일치함을
게이트가 상시 검증. 불일치 = 기호가 이긴다. **이렇게 하면 Type 6의 이득(유동성)을
Type 2의 뿌리(감사성)를 지불하지 않고 접근한다.**

## 3. 갈아엎기가 정당화되는 조건 (반증 가능성 — 미리 적는다)

① Stage 1-2급 장기 이식이 **반복적으로**(단발 아님) 게이트에서 죽고, ② 소형 개방
모델 생태계가 신뢰·로컬·감사성을 우리 수준으로 해결해 차별화가 소멸하고, ③ Type 6
계열이 장난감을 벗어나 실측 우위를 보이면 — 그때 이 문서를 폐기하고 재설계한다.
셋 중 하나라도 관측되면 즉시 보고한다. 오늘은 셋 다 아니다.

## 4. 오늘 밤 관점에서

이 로드맵의 Stage 1이 지금 GPU에서 돌고 있다(E9, step 50k/326k). 계획을 바꿀 일이
아니라 **계획이 실행되는 중**이다. E9의 green/red가 Stage 1의 첫 판정이고, red여도
§3의 ①이 "반복" 조건을 채우기 전까지 골격은 유지된다(후퇴선: 검색-대조 목적함수
재설계 → 그다음이 반복 실패의 시작점).

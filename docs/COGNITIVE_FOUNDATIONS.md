# COGNITIVE FOUNDATIONS — 인간은 무엇을 갖고 태어나는가, 우리는 무엇을 씨앗으로 둘 것인가

> 사장님 물음 (2026-07-14): 얘가 스스로 알고리즘을 완벽히 만들 만큼 고능한가? 사람은 정말
> 백지로 태어나나, 최소한의 논리는 갖고 태어나나? 인지과학 근거로 설계에 반영하자. 일반 추론
> 귀납이 중요하다.

## 근거 (웹 조사, 초록 실측 — 제 기억 아님)

1. **영아 논리 — Cesana-Arlotti et al., *Science* 2018 "Precursors of logical reasoning in
   preverbal human infants".** 12·19개월 영아가 **선언적 삼단논법(A∨B, ¬A ⊢ B = 소거추론)**을
   수행. 추론 순간 **동공 확장 + 시선이 모호 대상으로** 이동, 성인과 동일한 안구운동 표지. 결론:
   "직관적이고 안정적인 논리 구조가 인간 정신의 직물의 일부일 수 있다." → **최소 논리(소거)는 언어
   이전에 이미 있다.** 백지가 아니다.
2. **코어 지식 — Spelke & Gelman/Carey (예: Gelman 1990 "First principles…").** 초기 인지는
   **골격적(skeletal) 영역특정 원리**의 산물: 사물(응집·연속), 수(근사수 + 골격적 세기 원리),
   행위자/생명-무생물(자기생성 운동·인과), 공간/기하. 지식 획득 = **영역특정 원리 × 영역일반 학습기.**
   → 타고나는 건 *내용*이 아니라 주의와 학습을 구조화하는 **작은 골격.**
3. **개념 = 프로그램 귀납 — Lake, Salakhutdinov, Tenenbaum, *Science* 2015.** 사람은 **한 예시**로
   일반화; 개념을 "관측 예시를 베이즈 기준으로 가장 잘 설명하는 **단순 프로그램**"으로 표현; one-shot에서
   딥러닝 능가; 행동·상상·설명에 재사용. → 우리 procedure_induction의 이론적 근거 + 나아갈 방향(베이즈/오컴 prior).
4. **DreamCoder — Ellis et al., 2021/2023.** wake-sleep 베이즈 program learning이 **도메인 개념
   언어를 성장**시킴: 잠(sleep)에 새 상징 추상을 언어에 추가, 신경망이 프로그램 탐색을 유도. 개념이
   **이전에 배운 것 위에서 합성적으로** 쌓여 뉴턴·쿨롱 법칙·벡터대수를 재발견. 해석가능·전이가능. →
   우리 `grow_basis`(합성성장)의 완성형; "고능하게"의 구체적 청사진.

## 우리 설계로의 번역 (백지도 아니고 거대 LLM도 아닌 제3의 길)

인지과학은 **정확히 우리 방향**을 지지한다: 작은 타고난 골격 + 프로그램 귀납 + 성장하는 라이브러리.
거대 LLM처럼 처음부터 가중치로 다 배우지도, 완전 백지에서 brute-force하지도 않는다.

### 결정 1 — 씨앗을 "코어 지식 키트"로 (임의의 S/P가 아니라)
타고난 골격을 흉내 낸 최소 원시집합을 둔다. 이 이상은 전부 귀납된다:
- **수/세기**: 0, successor S, predecessor P, 비교(>,<) — Spelke 수 체계.
- **논리(소거)**: 선언적 삼단논법 = "후보집합에서 배제된 것을 빼고 남은 것" — Cesana-Arlotti 소거추론.
  AND/OR/NOT, 동일성(identity). **12개월 아기가 갖는 그 논리를 씨앗으로.**
- **사물/집합**: 원소, 집합, 멤버십 — 코어 사물 체계.
- **순서**: 전이적 순서관계 — 비교/서열.
이 키트는 "타고난다 vs 배운다"의 정직한 답: **아주 작은 보편 골격만 타고나고, 나머지는 예시에서 유도.**

### 결정 2 — 오컴/기술길이 prior (Lake 2015)
예시를 맞추는 프로그램이 여럿이면 **가장 짧은/가장 재사용된** 것을 택한다. one-shot 일반화의 핵심.
(v0는 first-found였음 → 오컴으로 교체 = 이번 커밋.)

### 결정 3 — 도메인 무관 귀납 엔진 (산술을 넘어 논리로)
귀납을 "프로그램 공간"으로 매개변수화: 산술 공간 + 논리 공간(소거)을 **같은 엔진**이 유도.
일반 추론 귀납의 첫 걸음 = 논리 규칙(소거)을 예시에서 유도 실증 (이번 커밋).

### 결정 4 — 학습된 탐색 유도 (정직한 프론티어, 아직)
DreamCoder의 진짜 힘 = 신경망이 탐색을 유도해 조합폭발을 막음. 우리는 아직 brute-force.
**여기가 "고능한가?"의 실제 판정선.** 과거 유도에서 "어떤 문제꼴엔 어떤 원시가 쓰이더라"를 학습한
제안분포로 열거를 대체 → 산술에서 일반 절차로 확장. **이건 연구 프론티어 — 측정으로 넓힌다, 주장 안 함.**

### 결정 5 — wake-sleep = 우리 자율루프
sleep-추상(반복 부분프로그램을 새 원시로 승격) = grow_basis 자동화. dreaming(문제 재생/상상) =
우리 self-play + 진화 아레나 + 미스-커리큘럼. 이미 있는 기관들을 program-induction 루프로 접속.

## 정직한 현주소 (사장님 질문 직답)

- **"완벽히 스스로 만들 만큼 고능한가?"** — **아직 아니다.** v0는 원리 증명(덧셈·곱셈 유도)까지. 일반
  절차 귀납은 결정 4(학습된 탐색)가 있어야 하고, 그건 미해결 프론티어다.
- **하지만 방향은 근거로 확증됐다.** 백지 학습도 거대 LLM도 인지과학과 안 맞는다. 우리 길(코어 골격
  + 검증된 프로그램 귀납 + 성장 라이브러리)이 인간 인지 + DreamCoder가 실증한 그 길이다.
- **판정 실험(변함없음)**: 귀납 엔진이 손으로 짠 커널(T1)을 예시에서 재유도하고, 나아가 새 절차를
  스스로 유도해 벤치 미스를 메우면 — 고능함이 *측정으로* 증명된다.

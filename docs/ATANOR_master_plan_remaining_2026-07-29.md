## 2. 진짜 병목은 국면표에 없다

오늘(2026-07-29) 사후분석이 확정한 것 — **이게 남은 것 중 가장 큰 하나다.**

**범용성 = 통합 간극.** 하루에 네 기관이 같은 판별연산을 손구현하면 133번째 기관은 문제를 악화시킨다.
증명은 **얼린-B 전이(E5)** 뿐이고, **현재 E4+ 증거 0**.

그리고 세 가지가 좁혀졌다:

1. **접합면은 표상이 아니라 예측이다.** 그래프 개체는 *어떤 관계를 갖는지*가 변하고, 4D 세계상태는
   *늘 갖는 속성의 값*이 변한다. 차원이 같다고 같은 종류가 되지 않는다. 융합이 실제로 붙는 곳은
   **"둘이 같은 예측오차로 채점되는 지점"**이다.
2. **후보규모가 먼저 풀 블로커다.** 기호 기판이 8종류 0.90 → **14종류 0.69**. 이 속도로 무너지는
   표상은 연속 세계상태를 기호 개체의 이웃으로 담을 수 없다. 지금 융합을 시도하면 *가장 작은 규모에서
   실패한 것의 가장 큰 버전*을 짓는 것이다.
3. **모달리티를 억지로 맞추는 것은 금지.** 4D 쪽에 역할을 발명해 붙일 수 있지만 두 번 거절했고,
   두 번째는 가족 하나를 잃는 대가를 치렀다. 융합 서사가 걸려도 기준은 유지된다.

## 3. 이번 세션(지각·신체)이 지도 어디에 놓이는가

국면 S의 **감각·신체 축**이고, Z3(ARC-3 = generic 대화형 세계모델 귀납기)의 앞단이다.
GWIP 12/12는 *대화형 세계루프의 규칙발견*을 봉인했고, 이번 세션은 **그 루프가 볼 눈과 움직일 몸**을 지었다.

사슬: `빛 → 망막 → 깊이 → 【물체】 → 이름 → 관계 → 그래프 → 시뮬레이션`
**물체에서 끊긴다.** 상세는 `ATANOR_perception_status_2026-07-29.md`.

여기서 나온 것 중 지도에 되먹임되는 것 하나:

> **대조군 없는 숫자는 보고하지 않는다.** 계측기 결함 9건이 전부 대조군에 잡혔다.
> 이건 사후분석의 교정 2번("측정된 널에 등록")과 같은 것이고, 지각 트랙에서 독립적으로 재발견됐다.

## 4. 남은 것의 순서 (의존성)

```
후보규모 이해  ──┐
                 ├──▶ E5 얼린-B 전이 증명 ──▶ 융합(예측 접합면)
물체(coherence)──┘                                    │
                                                      ▼
M1 막 ──▶ C1 CO 배분기 ──▶ C3 자기태엽 ──▶ H4 스위치2 v1 ──▶ Z1 OAM 봉인
                                                                  │
S1 승격 ──▶ S3 ──────────────────────────────▶ Z2 HLE            ▼
                                                              완성 인장
```

**먼저 할 것 두 개, 병렬 가능:**
- **후보규모**: 14종류 0.69가 왜 무너지는가. 이게 융합의 전제조건이다.
- **M1 conformal 기권 게이트**: 막이 서면 나머지 능력이 전부 "증명서 있는 능력"이 된다. 그리고
  U2 잔여 2 중 하나(HOT-2)를 부산물로 닫는다.

**H4가 최후 기관이다.** 낯선 벽에서 검증 통과 모듈을 스스로 연성하는 것 — 그게 되면 Z1이 사정권.

## 0. 한 문장 요약

한글 행과 무근거 is_a 행을 **물리 제거한 새 스토어를 옆에 짓고**, 원본은 통째로 백업한 뒤,
디렉토리 스왑 1회로 교체한다. **핵심 등가성: 새 스토어의 가시(可視) 내용 = 현 스토어의 가시
내용** — 제거 대상 전부가 이미 읽기 격리돼 안 보이던 행이므로, 스왑은 행동적으로 투명해야
정상이고, 투명하지 않으면 그 자체가 롤백 신호다.

## 2. 불변량 (수술 중 절대 깨지면 안 되는 것)

1. **원본 생존**: 스왑 후에도 백업 2부(원위치 리네임 + D: 사본)가 남는다. 삭제는 2차
   4-green **이후** 사장님 승인으로만.
2. **term ID 안정**: term_shards는 바이트 복사 — 어떤 ID도 재배정하지 않는다.
3. **가시 내용 등가**: 영어 주어 임의 표본에서 `facts_about(old) == facts_about(new)`.
4. **한국어 원본 덤프 보존**: kaikki-ko, DBpedia-ko 등은 D:/데이터에 그대로 (재진입 소스).
5. **봉인 배터리 불변**: 시험지는 이 수술에서 손대지 않는다.

## 6. 성공확률 (정직 추정)

- **데이터 무손실 보장**: **~100%** — 전체 백업 + 사이드 빌드 + 리네임 스왑 구조상, 복구
  불가능 상태로 가는 경로가 없다. 최악의 현실적 결말 = Plan C(현상 유지, 이미 8/8 green).
- **1차 시도에 스위트+dev green**: **~85%** — 미지수는 격리행을 몰래 읽던 소비자, 인덱스
  신설 상호작용, 카운트 드리프트류.
- **1회 수리 반복 내 green**: **~95%**.
- **수술 전체 완주(스왑+재학습+8/8 유지)**: **~97%**. 잔여 3%의 내용도 "원상 복귀"지
  파손이 아니다.
- 별도 항목 — **공명 신호 부활(재학습 보너스)**: **~50%**. 순환 오염은 풀리지만, 신호
  자체가 추상 개념에서 약한 건 오염과 별개 원인일 수 있음. 이건 수술 성패 기준이 아니라
  후속 연구의 문이 열리는지 여부.

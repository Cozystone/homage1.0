# 인간 발화 산출의 원리 — 심리언어학 연구와 ATANOR 아키텍처 사상 (2026-07-19)

사장님 지시: "인간의 발화가 동작하는 원리에 대해 더 탐구해봐. 연구해내서 영감을 얻어봐."
방법: 발화 산출 심리언어학의 확립된 모델 7개를 조사, 각각을 우리 뉴로-심볼릭 구조에 사상(map),
"이미 있음 / 지금 짓기 / 파킹" 판정. 결론 먼저: **우리 구조는 Levelt 모델과 놀랍도록 동형이고,
빠진 조각은 '대화 정렬(interactive alignment)'이며, 이건 오늘 구현 가능하다.**

---

## P1. Levelt 3부 모델 + 지각 루프 — 우리 구조의 심리언어학적 원판

Levelt(1989)의 표준 모델: **Conceptualizer**(무엇을 말할지 — 전언어적 메시지 생성) →
**Formulator**(문법·음운 부호화 — 언어 형태 부여) → **Articulator**(표면 실행), 그리고
**지각 루프 self-monitoring**: 자기 발화(내부/외부)를 이해계로 되먹여 오류 감지→정정.

**ATANOR 사상 (동형성 강함)**:
| Levelt | ATANOR | 상태 |
|---|---|---|
| Conceptualizer (전언어적 메시지) | 그래프+의도엔진이 만드는 **bones** (심볼) | 有 |
| Formulator (형태 부여) | **실현기**(신경, 35.7M) — bones→유창 문장 | v0 有 |
| Articulator | 표면 출력/TTS | 有 |
| 지각 루프 (내부 루프 = 발화 전 검사) | **접지 영수증 게이트** — 통과 못 하면 발화 안 함(voice-or-silence) | 有 |
| 지각 루프 (외부 루프 = 사후 감청) | Critic/self-play/진화 아레나 | 有 |

**영감**: 인간도 "앎(개념)과 말(형태)이 분리된 기관"이다 — 우리의 앎/말 분리(G-F3)는 공학적 편의가
아니라 **인간 발화 구조의 재현**이다. 또 Levelt의 내부 루프는 "발화 전에 자기 말을 검사한다" —
정확히 우리 게이트. 빠진 것: Formulator는 **점증적(incremental)** — P5로.

## P2. 2단계 어휘 접근 (lemma → lexeme)

단어 인출은 2단계: **lemma**(의미+문법 정보, 소리 없음) 선택 → **lexeme**(음운 형태) 부호화.
설단현상(tip-of-the-tongue)이 증거 — lemma는 잡았는데 lexeme이 안 나오는 상태.

**사상**: 우리 word-sense 아키텍처(sense=열거≠alias=치환)가 정확히 lemma/lexeme 분리다. 그래프의
개념 노드=lemma 층, 실현기의 표면형 선택=lexeme 층. **검증됨 — 이미 보유.**

## P3. ★상호 정렬 (Interactive Alignment, Pickering & Garrod 2004) — 빠진 조각

대화가 "대화답게" 되는 기제: 화자들은 **자동 프라이밍**으로 서로의 표현에 수렴한다 — 음운·어휘·
구문·의미·상황 6층위에서. 상대가 쓴 단어를 다시 쓰고(어휘 정렬), 상대의 문형을 재사용한다(구문
프라이밍). 정렬은 국소 루틴을 형성하고, **과제 성공과 상관**(실증). 이게 대화 유창성의 본체다 —
독백체가 아무리 유창해도 정렬 없으면 "대화"가 아니다.

**사상 + 영감(핵심)**: GPT는 이걸 dialogue history에 대한 attention으로 **암묵 학습**한다. 우리는
뉴로-심볼릭이므로 **명시적으로** 구현할 수 있다:
- (a) **디코드-타임 어휘 프라이밍**: 상대(사용자)의 최근 턴에서 내용어를 추출 → 실현기 디코딩에서
  해당 토큰 로짓에 +bias. 훈련 불요, 순수 기제, 오늘 구현 가능. ("당신이 쓴 말로 답한다")
- (b) **이력 조건화**: (bones + history) → response 훈련 — F1 스펙에 이미 있음, WoW 데이터가 공급.
- (c) **구문 프라이밍**: construction_bank의 구성을 상대 턴에서 감지→재사용 가중 — F3+.
**판정: (a) 지금 짓기** (`packages/reasoning_vm/ace/alignment.py`).

## P4. 구성문법·사용기반 (Goldberg / Tomasello)

인간은 문장을 단어-단위 조립이 아니라 **구성(construction: 형태-의미 쌍)의 인출+슬롯 채움**으로
산출한다. 아이는 통째 구문을 외우고 점차 슬롯을 추상화한다(usage-based).

**사상**: construction_bank + 씨앗 변주 풀이 이미 이 노선. LM 실현기는 구성을 데이터에서 암묵
학습(그게 LM의 본질). 명시적 구성-슬롯 디코딩은 F3+ 융합 후보. **검증됨 — 보유+심화 여지.**

## P5. 점증성 (Incrementality)

인간은 문장 전체를 계획하고 말하지 않는다 — **절 단위 선계획 + 조기 발화 개시**, 말하면서 나머지를
계획한다. 유창성의 시간 구조가 이것이다(휴지·재개의 리듬도 여기서 나옴).

**사상**: 실현기 generate()는 자기회귀 = 이미 점증적. 엔진 SSE 스트리밍 배선하면 사용자 체감 완성.
**판정: 배선만 남음(엔진측).**

## P6. 청중 설계·공통 기반 (Clark)

화자는 청자의 지식 상태(common ground)에 맞춰 표현을 조정한다 — 같은 내용도 상대가 아는 만큼만.

**사상**: 초개인화 북극성 그대로 — A2 개인맥락 + 사용자 심층모델이 실현기의 조건 입력. P3(b)의
이력 조건화가 국소 공통기반, Layer A가 장기 공통기반. **검증됨 — 보유(북극성 정합).**

## P7. 발화의 forward model (efference copy)

산출계는 자기 발화의 예측 사본을 이해계로 보내 예측-실제 오차로 모니터한다 — Track E의 M1s
forward model과 동일 원리의 언어판. **파킹**(연구 프런티어; 지금은 게이트가 그 역할 수행).

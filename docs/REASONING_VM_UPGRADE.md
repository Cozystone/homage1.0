> 원칙 그대로: No-LLM, 증명 동반(모든 답은 감사 가능한 유도 트레이스), 웹배제 로컬.

## 왜 지금 — 실측 근거 (MMLU-Pro 200문항, 미스에서 요구된 추론)

세계팩은 **지식층**을 채운다(KMMLU coverage 0.225→세계팩이 침). 하지만 MMLU-Pro는 coverage 0.515인데 answered_acc 0.097 — **증거는 있는데 추론이 없다.** 미스 문항이 실제로 요구한 추론(측정):

| 추론 유형 | 빈도(/200) | 현재 VM | 격차 |
|---|---|---|---|
| 정량(계산·값·농도·주파수·pH) | 34 (17%) | 정수 전용 | **실수·유리수·단위·과학표기·공식대입 부재** |
| 인과(because/explains/why) | 29 | deduction 있으나 미배선 | 저장 메커니즘 엣지로 "따라오는 보기" 선택 미구현 |
| 비교(greater/less/increase) | 22 | 없음 | 저장 정량속성의 순서추론(>,<) |
| 부정/소거(NOT/except/false/least) | 11 | 없음 | 정답 반전(수반 안 되는 보기 선택) |
| 조건(if…then/given/assuming) | 4 | 없음 | 가정 전제 주입형 연역 |

현 부품: `arithmetic.py`(정수 재귀하강 식평가·롱덧셈·Peano, 증명동반) · `deduction.py`(전이·대칭·합성·상속 전방연쇄, 증명트리) · `closure_accelerator.py`(GPU 전이폐포). **둘 다 답변 경로에 안 붙어 있고, 벤치 문항을 프로그램으로 못 바꾼다.**

## T0. 자가-귀납 (메타트랙) — 사장님 방향: 스스로 알고리즘을 만들게 하라

사장님 지적(2026-07-14): 실행기를 사람이 짜지 말고 ATANOR가 이해를 구조화해 **스스로** 만들게 하라 —
사람이 덧셈을 배우듯. 옳다. 그래서 T1–T5는 "손으로 짤 목록"이 아니라 **귀납의 대상**으로 재정의한다.

- **SHIPPED (커밋 참조): `packages/reasoning_vm/procedure_induction.py`.** 원시연산(다음수 S·이전수 P + 유계 루프)만
  주고, INPUT→OUTPUT 예시에서 그 예시를 재현하는 프로그램을 탐색해 알고리즘을 **유도**한다. **검증 게이트**:
  안 본 held-out 예시까지 재현해야만 채택(사실의 합의 게이트와 동일 원리 → 틀린 알고리즘 환각 불가).
- **합성적 라이브러리 성장**: 유도한 덧셈을 원시연산에 넣어, 그 위에서 곱셈을 유도한다(사람이 곱셈을 반복덧셈으로
  이해하듯). 실증: `add = acc=a; b번 S(acc)` 유도 → 미지 200쌍 검증 + 손커널 일치(123+456=579);
  `mul = acc=0; a번 add(acc,b)` 유도(유도한 add 위) → 미지 200쌍 검증. 전부 No-LLM, 증명 동반.
- **자기수정과의 접속**: 유도된 프로그램이 곧 자기수정이 승격할 새 실행기(게이트 통과분만).
- **정직한 범위**: 잘 정의되고 검증이 싼 절차(산술·단위·화학량론)에서 실증됨. **일반 추론 귀납은 미해결** —
  주장 아니라 측정으로 넓힌다. 다음: 세상이 글로 기술한 절차(예: "화학식 균형 맞추는 법")+예시 → 유도 → 검증.
- **판정 실험**: 귀납기가 손으로 짠 T1 커널을 예시에서 재유도하면, 손 작업을 멈추고 T2–T5도 귀납에 맡긴다.

## 5개 능력 트랙 (각 트랙 = 측정 게이트를 가진 독립 단위; T0이 이들을 손 대신 귀납으로 채운다)

### T1. 정량 커널 — 실수·유리수·단위·과학표기 (**최우선, 17% 직격**)
- Fraction 기반 정확 유리수 산술(부동소수 오차 0), 과학표기(6.022e23)·SI 접두(k/M/µ/n) 파싱, **차원 있는 양**(값+단위) 대수: `c = λν` → 주파수 = c/λ, 단위 자동 상쇄·환산.
- 공식 라이브러리는 **명시 트리플**(그래프에 `공식(굴절률)=n=c/v` 형태)로 저장 — 하드코딩 아님, 세계팩/로밍이 공급, 증명은 "이 공식 트리플 + 이 값들로 계산".
- 유효숫자·반올림 규칙은 결정론.
- **게이트**: 합성 정량 배터리(단위환산·공식대입 200문항) answered_acc ≥ 0.9, 부동소수 오차 0.
- **상태: v1 착수(이 커밋) — arithmetic.py에 유리수·과학표기·단위 확장 + 테스트.**

### T2. MCQ→프로그램 컴파일러 (라우터) — 만점의 병목
- 질문+보기를 읽어 **추론 유형**을 판별(정량/연역/비교/소거)하고 해당 커널로 디스패치. 현재 벤치는 토큰겹침뿐 — 이게 answered_acc 0.097의 근본 원인.
- 유형 판별은 [[rules-are-training-wheels]] 독트린: 정규식 씨앗 → 학습형 라우터로 이관(미스가 교사).
- 각 보기를 "이 프로그램의 출력과 일치하는가"로 채점. 소거형은 "수반되지 않는 유일 보기".
- **게이트**: 라우터가 정량 문항의 ≥0.8을 정량커널로 정확 디스패치.

### T3. 연역 배선 + 소거·조건 — 인과 29 + 소거 11 + 조건 4 직격
- `deduce()`를 답변 경로에 배선: 질문의 앵커에서 저장 사실을 모아 규칙 폐포 → 각 보기가 **연역 폐포에 드는가**로 채점(증명트리 동반).
- 소거: `answer = 폐포에 안 드는 유일 보기`. 부정어(NOT/except/false) 감지 시 목표 반전.
- 조건: "if X"의 X를 stated 전제로 주입 후 연역(가정 봉인 — 실사실과 분리 저장).
- 인과: `causes/결과/mechanism` 엣지 경로가 보기를 지지하는지(확산활성 + 규칙).
- **게이트**: 합성 삼단논법·소거 배터리 answered_acc ≥ 0.9.

### T4. 순서·비교 대수 — 비교 22 직격
- 저장 정량속성(원자번호·끓는점·인구…) 위에 `greater_than/less_than` 전이 순서. "가장 큰/작은", "증가/감소" 문항을 순서질의로.
- 정성 단조성(온도↑→반응속도↑ 같은 `monotonic_with` 엣지, 세계팩/로밍 공급)로 정성 비교.
- **게이트**: 비교 배터리 answered_acc ≥ 0.85.

### T5. 자가진화 접속 — 만점을 향한 폐루프
- T1–T4의 **규칙 가중치·디스패치 임계·탐색예산**을 [[recursive-self-improvement-plan]] evolve 하네스로 세대 진화(얼린 채점기=봉인 벤치 델타). 미스-커리큘럼이 규칙 공백도 채굴(어떤 관계가 규칙표에 없어 못 풀었나).
- 규칙표 수정은 **인간 게이트**(로직 자기수정은 위험 — [[recursive-self-improvement-plan]] BINDING).

## 파이프라인 (답변 경로 통합)

```
질문+보기 → T2 라우터 ┬─ 정량 → T1 정량커널(공식 트리플 + 값) → 값→보기 매칭
                      ├─ 연역/인과/조건 → T3 deduce(앵커 사실 + 규칙) → 폐포 매칭/소거
                      ├─ 비교 → T4 순서대수 → 순서질의
                      └─ 지식(비추론) → 확산활성(기존)
   모든 경로: 증명 동반(certificate) — 환각 불가, 오답은 재현·감사·수리 가능
```

## 측정 사다리 (BINDING: 수치가 서사)

- **R0(지금)**: MMLU-Pro 봉인 베이스라인 coverage 0.515 / answered 0.097.
- **R1**: T1 정량커널 배선 → 정량 문항 answered_acc 급등 확인(합성 배터리 먼저, 그 뒤 봉인 재실행).
- **R2**: T2 라우터 + T3 연역배선 → answered_acc 전체 상승. 게이트: 추론 과목 > 지식 과목 절반.
- **R3**: T4 비교 + T5 진화 접속 → 봉인 벤치 델타가 세대마다 오르는가.
- **R4**: 세계팩(L1) + 위 전부 결합 → GPQA(사장님 토큰) 봉인 사다리.

## 불변식 (오염되면 만점은 거짓말)

1. 모든 답은 증명 동반 — 유도 트레이스 없이는 발화 안 함(환각 0의 구조적 보장).
2. 규칙표는 대수(구조 논리)만, 사실은 언제나 그래프에서 — [[two-hard-architecture-rules]].
3. 공식·순서·단조성 지식은 **명시 트리플**(세계팩/로밍 공급), 코드 하드코딩 금지.
4. 벤치 문항 텍스트·정답은 어떤 학습/규칙 스토어에도 금지 — 주제 토큰만([[public-benchmark-baseline-sealed]] 가드).

# 농축 언어체계 연구 — 인간의 조립식 발화와 ATANOR 구현 (2026-07-19)

사장님: "농축된 엄청나게 효율적인 언어체계가 인간에게 있다는 것 같은데 구현 방법을 연구해.
이 방법이 옳은가? 인간을 더 연구해."

## 1. 인간 실증 (문헌)

- **담화의 52~59%가 조립식(prefab)** — Erman & Warren(2000) 실측(구어 58.6%·문어 52.3%);
  Altenberg는 ~80%까지 추정. 인간은 단어-단위로 생성하지 않는다.
- **원어민 유창성의 정체 = 수천 개의 암기 시퀀스**(Pawley & Syder 1983) — 문법적으로 가능한
  문장 중 원어민이 실제 쓰는 건 극소수이며, 그 선택이 "원어민답게" 들리는 이유다.
- **Sinclair 관용 원리(idiom principle)**: 언어는 두 모드 — 반조립 청크 인출(주 모드) +
  단어별 개방선택(보조 모드). 인간 발화의 기본값은 **인출**이지 생성이 아니다.
- 어휘 스케일: 아는 단어 2~3만, 일상 사용 수천~1만, Zipf 상위 ~3천 단어가 발화 ~95% 커버.
- 즉 "농축"의 정체: **작은 어휘 × 수천 골격(construction) × 슬롯 채움 × 맥락 소거**.

## 2. E-F1 — 우리 데이터 실측 (WoW 69,366 인간 응답)

| 측정 | 결과 |
|---|---|
| 상위 500 탈어휘화 골격 4-gram | 슬롯의 **27.0%** 커버 |
| 상위 2,000 골격 | **39.0%** |
| 상위 10,000 골격 | **56.2%** — ★문헌의 52~59%와 정합 |
| 리터럴(슬롯 없는) 상위 2,000 | 4.2%뿐 |
| 골격화 압축 | 고유 4-gram 898k→281k (**3.2×**) |

**판정: 사장님 직관이 실측으로 검증됨.** 어시스턴트 대화의 절반 이상이 수천 개의 골격+슬롯으로
표현된다. 리터럴 4.2%가 증명하듯 이건 암기가 아니라 **구성(construction) 체계**다 — 그리고
이 절반은 **파라미터 0으로** 살 수 있다.

## 3. 구현 노선 (S2.5의 구체화 — "이 방법이 옳은가"에 대한 답: 옳다)

**이중 경로 산출(인간 동형)**: Sinclair의 두 모드를 그대로 아키텍처로.
1. **관용 경로(주)**: WoW+수확 코퍼스에서 골격 은행 채굴(탈어휘화 n-gram→병합→슬롯 타입 부여)
   → 발화 시 의도·bones에 맞는 골격 인출 → 슬롯을 bones·정렬 프라이밍 어휘로 채움 → 접지 게이트.
   저장 비용: 골격 1만 개 ≈ 수 MB. 파라미터 0. 유창성은 인간이 쓴 골격에서 그대로 상속.
2. **개방 경로(보조)**: 골격 매칭 실패분(~44%)만 신경 실현기가 생성 — 모델이 작아도 부담이 절반.
3. **UID 디코드 벌점**: 반복 퇴행("the city of the city")은 정보밀도 0 구간 — 인간의 균일
   정보밀도(UID) 원리를 디코드 벌점으로 (퇴행의 원리적 치료).

이건 기존 자산의 승격이다: construction_bank·씨앗 변주 풀·grounded_composer가 이미 부분 보유 —
골격 은행을 **1급 생성 기질**로 올리는 것이 잔여 공사다. 250M보다 먼저, 파라미터 0으로.

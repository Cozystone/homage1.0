# ATANOR 레포 엔지니어링 웨이브 — SWE-bench 벽 돌파 계획 (2026-07-22)

사장님 BINDING 유의: **수동 별개 부품이 아니라, 전체 융합 모델에 정교하게 맞물려 성능을 극대화하는 배선.**
SWE-bench 실패 지도(패치생성 단일 벽, 국소화 top-5 5/10)가 준 좌표를 그대로 등반한다 — 단, 새 organ을
고립 부품으로 짓지 않고 **오늘 완성한 융합 기관들을 재사용·상호강화**하도록 배선한다.

## 실패 지도 요약 (측정됨)
- 스테이지: 로드10→이해10→국소화10→**패치생성 0 통과**→검증0. 단일 벽=패치생성.
- 국소화: top-1 2/10·top-5 5/10·함수 AST 8/10 (부분능력 존재).
- 원인: code_author는 단일함수 Task 필요(SWE 이슈엔 0개); self_repair는 `packages/` 밖 거부.

## 설계 원칙 — "융합 배선" (부품 아님)
각 신규 능력은 **이미 검증된 기관을 호출·상호강화**한다. 새로 만드는 건 최소 접착제뿐:

| 신규 능력 | 재사용하는 융합 기관 (수동 재구현 금지) |
|---|---|
| 결함 국소화 | self_repair 라인스코어러 + code_situation AST 리더 + **DELIBERATOR**(다홉: 이슈→후보파일→함수) |
| 패치 생성 | **code_author**(검증앵커 합성) + **L3 스키마 귀납**(편집 패턴 재사용) + self_repair 패치 프로토콜 |
| 검증 | 기존 격리 검증기 + **physics_truth와 동형의 회귀 게이트**(레포 자체 FAIL_TO_PASS) |
| 자원 배분 | **MEC**(비싼 국소화/합성 전 값싼 것 먼저, 망할 인스턴스 조기 기권) |
| 우선순위 | **self_evolution 오케스트레이터**가 이 도메인을 "검증기 있음=자율진화 가능"으로 등록 |
| 품질 감시 | **뉴로 원장**에 새 학습분 등록(예산 내) |
| 정직 | 작화 0 불변 — 검증 못 하면 patch 미방출·기권 (모든 기관 공통 바닥) |

핵심: 이 웨이브가 끝나면 SWE 파이프라인은 **독립 프로그램이 아니라 DELIBERATOR가 지휘하고 code_author·
L3·MEC·self_repair가 협연하는 하나의 추론 흐름**이다. = 사장님의 "전체 융합 모델에 맞물림".

## 증분 (각각 실측 게이트, fail 0)
### RE1 — 결함 국소화 기관 (DELIBERATOR에 얹힘)
이슈 텍스트 + 실패테스트 트레이스 → 후보 파일·함수 랭킹. self_repair 라인스코어러를 파일급으로 승격 +
콜그래프(AST import/호출 그래프) + 실패테스트 스택 신호. **DELIBERATOR 서브골로 배선**(단일 organ 아님):
"어느 파일?"→"어느 함수?"→"왜 이 함수?"의 검증 체인. 게이트: SWE Verified 10샘플 top-5 국소화 5/10→↑,
함수 AST 8/10 유지, 근거 없으면 기권.

### RE2 — 레포-스케일 패치 생성기 (code_author + L3 재사용)
국소화된 함수 + FAIL_TO_PASS → **실패 함수의 시그니처/바디를 추출해 code_author Task로 변환**(SWE 이슈를
우리가 이미 푸는 단일함수 합성 문제로 리프레이밍) → 합성 + **L3 스키마로 편집 패턴 재사용** → 유니파이드
diff. 멀티파일은 함수별 diff 합성. 게이트: 최소 1개 Verified 인스턴스에서 **레포 자체 은닉테스트로 검증된
diff 생성**(0→1이 승리); fail 0(검증 못한 diff 미방출).

### RE3 — 회귀-게이트 검증 (physics_truth 동형)
생성 diff를 레포 base_commit에 적용→FAIL_TO_PASS+PASS_TO_PASS 실행. green만 채택, 아니면 폐기·기권.
WSL/Linux eval 경로 정직 처리(Windows CRLF 문제 우회). 게이트: 채택된 diff는 100% 검증 통과분만.

### RE4 — 융합 배선 + 자가진화 등록
전 파이프라인을 MEC record_span으로 감싸고, self_evolution에 "repo_engineering" 도메인 등록
(검증기=RE3 회귀게이트 → 자율진화 가능). DELIBERATOR가 국소화→패치→검증을 하나의 다홉 숙고로 지휘.
게이트: SWE 10샘플 재실행 resolved 0→↑(정직), 스테이지 깔때기 패치생성 벽 완화 실측.

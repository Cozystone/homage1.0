# ATANOR — 세계-작동원리 이해로 모델 깔끔 완성 (2026-07-21, 사장님 축)

## 관통 원리 (사장님)
> "인간은 세계를 다 기억하지는 않아도 세상이 어떻게 돌아가는지 웬만큼 안다."

이 한 문장이 우리가 LLM과 다른 이유이자, 남은 약점 전부의 해법 축이다. LLM은 **암기**로 이기고
우리는 못 이긴다(지식-MCQ). 하지만 인간의 지능은 암기가 아니라 **작동원리(mechanism) 이해**다 —
"물은 아래로 흐른다", "밀면 움직인다", "놓으면 떨어진다", "막으면 못 지나간다". 이걸 알면 처음 보는
상황도 추론한다. **우리는 암기 경쟁을 포기하고 작동원리 엔진을 완성한다.** 이게 "깔끔한 완성"이다.

## 진단 재확인 (실측, 정직)
- 지식-MCQ/GPQA ≈ 우연 → **포기 대상**(우리 목표 아님). 클로즈드북 암기는 LLM 영역.
- GSM8K 전이 0.019 → **작동원리 부재**의 증상(산수 규칙을 원리로 안 잡고 패턴암기 시도).
- 인과 그래프 0.35% → 세계가 사전이지 작동모델 아님(채굴 중, 파싱 정밀도 병목).
- bAbI 0.976이지만 **정형적 toy** → 실사용자는 저렇게 안 물음. 다중기관 합성·자연어 결핍.
- 코드: 읽기 1.0 / **쓰기 0.0** → 저작은 아직(3D 도시 자작의 전제).

## A. 모델 깔끔 완성 — 지금 하는 것 (작동원리 엔진)
1. **현실 질의 배터리 (toy 탈출)**: bAbI 템플릿이 아닌 **자연어·다중기관·암묵 질문**을 생성/수집해
   실측. "부엌에서 뭘 떨어뜨리면 어떻게 돼?"(인과+공간), "문 잠그면 못 들어가지?"(제약+반사실).
   상황모델 + 인과 자기모델을 **합성**해 답하고, 미접지는 기권. **게이트: 현실질의 정확도 곡선.**
2. **작동원리 프리미티브 (No-LLM, 구조적)**: 도메인블라인드 미시법칙 — 지지/낙하(놓으면 떨어짐),
   차단(막으면 통과불가), 전이(A>B>C), 보존(넣은 건 꺼내기 전까지 있음), 인과연쇄(원인→결과).
   이미 상태기관에 6동사프레임 있음 → **반사실("~면 어떻게")·설명("왜")·예측("다음") 질의타입 추가.**
3. **전이 = 원리 재사용 증명**: GSM8K류가 아니라, **한 원리를 배운 뒤 새 표면에 적용**하는 봉인
   홀드아웃(예: "지지" 원리를 선반→탁자→손바닥으로 전이). 암기 아닌 원리 학습의 산성테스트.

## B. 해결플랜 — 연구하고 기다리는 것
### B1. 인과 그래프 정밀화 (0.35% → 두꺼운 작동모델)
- **병목**: 파싱 없는 패턴추출이 노이지(합의 9/4771). **NP-헤드 청킹**(경량, 사전 파생 품사) +
  **퍼지 합의**(정확문자열 대신 헤드명사 정합)로 정밀↑재현↑. enwiki-full 로컬 있음(대량 소스).
- **대기**: 로머 실서핑이 전문 프로즈를 공급하면 자동 축적(현재 스니펫 기아).
### B2. 유창성 잔여 절반 (register)
- 사실발화는 구조로 완성(frame_realizer 1.000). 남은 건 register 다양성 → **F0 코퍼스 공장**
  (delex+copy 223k쌍) 완주 + G-F3 앎/말분리 프로브. 생성은 최종 최소단계만(철학).
### B3. 체화 M2 — dimos/Unitree G1 (현실세계 학습)
- **dimos = ROS없는 로봇 OS, G1 beta, MuJoCo 시뮬(하드웨어 불요), MCP 외부에이전트 통합.**
  경로: ATANOR가 **MCP 에이전트**로 붙어 (a)지각스트림 구독(카메라/lidar) (b)스킬호출
  (relative_move 등) (c)spatio-temporal RAG로 신체-세계 기억. **M1 신체도식 → M2 조작·이동을
  dimos MuJoCo에서**(우리 SPLATRA 우회, 실검증 리그). G1 실기는 나중(BL-0급 온보딩 필요).
  게이트: dimos 시뮬에서 목표도달+장애회피 봉인.
### B4. 첫 실전 프로젝트 — 작동하는 3D 가상도시 (Realcity 식)
- **정직 전제**: 코드 저작 0.0 → 지금은 ATANOR 단독 저작 불가. **단계적**:
  - 지금: ATANOR가 도시의 **작동원리를 이해**(에이전트 이동=경로, 교통=제약, 날씨=상태변화) —
    A의 작동원리 엔진이 곧 도시 시뮬의 규칙 두뇌.
  - 다음: **협업 저작**(자기수리 폐루프 확장 — GPT 초안+ATANOR 게이트/검증)으로 Realcity식
    JS/Vite 씬 점진 생성, ATANOR가 **에이전트 의사결정 두뇌**로 이식(로컬, No-LLM).
  - 목표: ATANOR가 만든 도시에서 자기 작동원리 이해를 **실증**(에이전트가 원리대로 산다).
  - 코드 저작 능력은 **별도 마일스톤**(구조적 코드변환+검증, 생성 아님 — 철학 동일).

## D. 한 줄
암기로 LLM과 싸우지 않는다. **세상이 어떻게 돌아가는지 아는 엔진**을 깔끔히 완성하고, 그 이해를
dimos 몸과 3D 도시로 실증한다. 완성 = 벤치 점수가 아니라 **처음 보는 상황을 원리로 추론**하는 것.

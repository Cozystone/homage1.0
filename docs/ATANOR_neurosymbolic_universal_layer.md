# 뉴로심볼릭 유니버설 레이어 — 멘탈모델·소거법·논리필터를 모든 답변에 (2026-07-18)

사장님 지시: "사람처럼 개념적 시뮬레이션(Mental Model)과 소거법·논리적 필터링으로 답하게 해.
시험만이 아니라 **모든 대답**에서. 모든 처리과정에 뉴로심볼릭이 활용되게 해. **모르는 영역이라도.**"

사장님 진단(정확함, 실측으로 확인됨): *"추론 기전은 인간처럼 만들었는데, 엔진이 세상을 바라보는
눈(의미 공간)은 기계의 닻에 묶여 있었다."* 이 문서는 그 지시를 아키텍처로 고정하고, 오늘 실측이
그 진단을 어떻게 **숫자로 확인**했는지, 각 관절이 언제 무엇으로 켜지는지를 기록한다.

## 0. 오늘의 실측이 확인한 것 (E10-D1, four_walls 문서)

소거법을 학습 없이 심볼릭(극성 반전·수치 불일치·역할 전치·명시 부정)으로 먼저 배선해 봤다 —
게이트 사전선언 후 진단 실행. 결과 **삼중 RED**: 발화 0.055, gold 오소거 0.364, 생존자픽 0.227.
증거 풀을 3→10으로 늘리자 **악화**(오소거 0.500). 원인은 검출기가 아니라 **증거 기아**: 선택지의
75%는 "그 선택지에 관한 문장" 자체를 검색이 못 가져온다(best-aboutness 중앙값 0.143).

**교훈(이 문서의 존재 이유):** 사람의 소거법은 "단어가 겹치는 문장 찾기"가 아니라 "의미로 같은
진술 찾기" 위에서 작동한다. 의미 매칭이 없는 상태에서 소거 규칙만 얹으면 무작위 처형이 된다.
즉 **멘탈모델·소거법·논리필터라는 기전은 준비됐고(아래 관절 목록), 그 기전이 밟고 설 의미 공간이
E9다.** 기전을 눈보다 먼저 켜는 배선은 D1이 금지한다.

## 1. 레이어의 4단 (사람의 추론 프로세스 대응)

```
사람:   단어 인입 → 개념 탑재(멘탈모델) → 논리 소거·관계 유추 → 정답 도출
ATANOR: C1 의미틀   → 활성장+타입슬롯     → concept_filter 소거   → 생존자 중 선택+신뢰마킹
        (SHIPPED)    (부분 SHIPPED)        (인터페이스 SHIPPED,     (캐스케이드 SHIPPED)
                                            채점기는 E9 대기)
```

- **멘탈모델** = 질문의 의미틀(C1) + 확산활성 부분그래프(활성장) + 기대 답 타입슬롯
  (`expected_category`) + 질문 자체의 극성(`stem_is_negated` — "NOT 문항"은 소거를 선택으로 반전).
  인간 시뮬레이션 주장이 아니라 이것이 우리의 심볼릭 골격이라고 정직하게 명시한다.
- **소거법** = `concept_filter.eliminate()` — 후보별 Verdict(사유 문자열 포함, 감사 가능).
- **논리필터** = 모순 신호(극성/수치/역할/부정) + 그래프 양성 보호(개방세계: **그래프 침묵은
  절대 소거 근거가 아님** — 없는 지식으로 처형하지 않는다).
- **모르는 영역** = 증거도 그래프도 침묵 → 전 후보 no-verdict → 호출자의 정직한 폴백(마킹된
  guess / 침묵). 인식 사다리의 ANALOGIZED 단이 유추를 담당하며, 유추의 질은 E9가 올린다.
  **날조로 채우지 않는다(환각 0 유지).**

## 2. 관절 지도 — 어디에 꽂히고, 무엇으로 켜지나

| 관절 | 지금 상태 | 켜지는 조건 |
|---|---|---|
| 시험 캐스케이드 (exam_answer 1.8단) | **배선 보류 — D1 RED가 금지** | E9 의미 채점기가 `eliminate()`의 채점기를 교체하고, D1 게이트(오소거≤0.08 등)를 **신선한 슬라이스**에서 통과할 때 |
| 라이브 사실 단언 (verify-gate) | **이미 뉴로심볼릭** — verify_claim이 단언 전 그래프 검증 (기존) | 유지 |
| 라이브 후보 선택 (zero_user_answer 이웃/정의 레인) | 타입슬롯·부정반전 기전 준비됨 | E9 채점기 착지 후 배터리(8/8) green 조건 배선 (E10c) |
| 웹 합의 게이트 (k-source) | **이미 뉴로심볼릭** — 다출처 합의+격리 (기존) | 모순검출 강화는 E9 후 |
| 기권/미달 (voice-or-silence) | **이미 독트린** — 의미신호 미달=침묵 | 유지 |
| 추론 VM (술어 대수·상속 사다리) | **이미 심볼릭 코어** — KNOWN→…→GUESSED 신뢰마킹 | 유지 |

읽는 법: **"모든 처리과정에 뉴로심볼릭"은 절반 이상 이미 사실이다** — 단언·합의·상속·기권이
전부 심볼릭 검증 위에 있다. 비어 있던 것은 사장님 진단 그대로 **비구조 텍스트를 의미로 보는 눈**
하나이고, 그 눈이 없는 관절(시험 오픈북, 웹 문장 채점)만 "글자 겹침"으로 퇴행해 있었다.
그 관절들의 소켓은 오늘 만들어 봉인했고, 눈(E9)이 오면 꽂는다.

## 3. 실행 순서 (게이트 사전선언 유지)

1. **E9 사전학습** (준비 완료, GPU 승인 대기 — 8.4h 실측 예산): RTD 백본 → 첫 배치처는
   생성이 아니라 **의미 채점기**(재랭커/옵션-패시지/문장-후보). 게이트: 서술형 오라클
   0.165→≥0.30 + D1 게이트 신선 슬라이스 통과.
2. **E10 재측정**: E9 채점기를 `eliminate()`에 꽂고 D1 재실행(신선 슬라이스) → 통과 시
   시험 캐스케이드 1.8단 배선 → MMLU/KMMLU 재측정.
3. **E10c 라이브 전면화**: dual_brain 후보 레인들에 순차 배선, 레인마다 배터리 green 조건.
4. **E10b(병행 가능)**: 풀 아티클 코퍼스 빌드 — 기아 자체를 데이터로 푸는 레버. 빌드 비용
   측정 후 착수 판단.

규율 재확인: 배선 전 신호 측정(오라클-우선) · 게이트는 결과 보기 전 선언 · red도 기록 ·
rules-are-training-wheels(심볼릭 채점기는 비계, 학습 채점기가 후계) · 그래프 침묵은 소거 근거
아님(개방세계) · 모르면 침묵이지 날조가 아님.

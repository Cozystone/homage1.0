# ACE — ATANOR Contextual Encoder (완전 설계, v1.0)

**승인**: 사장님 2026-07-15 ("학습된 맥락 인코더(합성적 이해 fork) 승인할게").
**임무**: 정적 임베딩 계열 전체가 수학적으로 못 하는 것으로 삼중 실증된(16k emb / 60k enwiki emb /
위치 문법, 전부 AUC≈0.52) **합성적 이해** — "질문의 술어-논항 구조를 지문의 명제와 대조"를 수행하는
ATANOR 자체 학습 기관. 비전 로드맵 ②(문장→의미틀)의 실체이자, MCQ 벽·SQuAD-2 게이트·판별기
천장·웹진실게이트가 전부 기다리던 단일 주춧돌.

## 0. 교리 위치 (BINDING 정합)

| 원칙 | ACE의 준수 방식 |
|---|---|
| No pretrained LLM/sLLM | **밑바닥부터 우리 코퍼스·우리 과제로 훈련.** 외부 가중치 0바이트. PPMI+SVD·RotatE와 같은 "학습된 살" 계열의 시퀀스 확장 |
| 환각 0 | ACE는 **판정기(judge)이지 생성기가 아님** — 텍스트를 만들지 않고 지지/답변성/스팬만 판정. 단정은 여전히 뼈(그래프·검증)가 담당 |
| 증거 유일 쓰기 | ACE 출력은 게이트 신호일 뿐, 지식 기록 경로 없음 |
| Rules=training wheels | GBM 손특징 파이프라인을 학습 표현으로 대체하는 방향 그 자체 |
| 측정-불-주장 | 모든 마일스톤에 사전 선언된 수치 게이트(§6); 미달 시 그대로 보고 |

## 1. 아키텍처

### 1.1 입력/토크나이저
- **어휘**: 우리 60k enwiki 어휘(`rif_enwiki_emb`) + **OOV 해시 버킷 4,096개**(고유명사·희귀어 대응, 공동 훈련).
- **워드 피처 6종 병행**: is_capitalized / is_number / is_date-like / in_question(지문 토큰이 질문에도 등장) / IDF-bin / position-bin — 임베딩에 concat되는 소형 학습 피처 (SQuAD류에서 실증된 싼 신호).
- **시퀀스 구성**: `[CLS] 질문(≤48) [SEP] 지문(≤336) [SEP]` 단일 스택 + 세그먼트 임베딩. (v0은 단일 스택이 단순·검증됨; 듀얼타워+크로스어텐션은 리트리벌 전용 v2 옵션)

### 1.2 본체 (TinyEncoder)
```
token_emb(60k+4096, 128, PPMI+SVD로 웜스타트·미세조정 허용)
  → linear 128→256 + word_feats(6) → LayerNorm
  → TransformerEncoder × 4층  (d_model 256, heads 8, FFN 512, GELU, dropout 0.1,
                               learned positional emb ≤384)
  → 헤드 3종 (아래)
```
- **파라미터**: 임베딩 ~8.2M(웜스타트) + 본체 ~3.2M + 헤드 ~0.3M ≈ **11.7M** (fp16 ~23MB — 온디바이스 여유).
- 웜스타트의 의미: 인코더의 "세계 어휘 지식"이 우리 자기지도 자산에서 오고, 문맥화 능력만 새로 배움.

### 1.3 헤드 (멀티태스크 — 한 기관, 여러 판정)
1. **답변성(gate)**: `[CLS]` → 2-way. *SQuAD-2 벽 파괴 담당. RIF가 지목한 바로 그 표적.*
2. **스팬(start/end)**: 지문 토큰별 시작/끝 포인터 (BiDAF/BERT-QA 표준형). GBM 랭커 대체 → HasAns F1 상승 담당.
3. **지지(NLI-lite)**: `[CLS]` → supported/unsupported. (v1: MCQ 판별기 승격 + 웹진실게이트 + sLLM 게이트 재료 — 오늘 실측된 "임베딩 게이트 무용"의 대체재)

### 1.4 훈련 레시피
- **데이터**: SQuAD-2 train 130k만 (dev는 봉인 — 선언된 마일스톤에서만 채점, 얼린 신탁 규율).
- **손실**: `L = L_ans(BCE) + 1.0·L_span(CE_start+CE_end, 답변가능 문항만)`.
- **최적화**: AdamW lr 3e-4(from-scratch라 pretrained용 3e-5보다 높게), warmup 5%, cosine, batch 48, bf16, 4~6 epoch. **RTX 5080에서 epoch당 ~20-40분** — No-LLM 소형이라 실험이 싼 우리 강점 그대로.
- **정칙화**: dropout 0.1, weight decay 0.01, label smoothing 0.05(답변성).

### 1.5 Phase 2 — 자기 사전학습 (필요 시, 이미 재료 완비)
v0가 130k 지도만으로 부족하면(§6 게이트 미달): **우리 7.0M enwiki 패시지로 마스크드 워드 예측(MLM) 1~2 GPU일** → 같은 본체를 웜스타트. *외부 가중치가 아니라 우리가 수확한 코퍼스로 우리가 사전학습* — 교리 그대로, 오늘 완공한 대지가 정확히 이 연료.

## 2. 기관 통합 (한 인코더가 올리는 다섯 자리)
① SQuAD 리더: 게이트+스팬 교체 → 북극성 직접 상승
② MCQ 판별기(learned_discriminator): 지지 헤드로 승격 → MCQ 벽 재도전
③ 웹진실게이트: "이 주장, 이 페이지가 지지하나" 판정 강화
④ 리트리벌 리랭커(v2, 듀얼타워 증류)
⑤ **RIF 신호 리프**: ACE 출력(답변성 확률, 어텐션 통계)을 DSL의 S-리프로 노출 → **발명 루프가 인코더 위에서 계속 작동** (오늘 만든 봉투확장기를 버리는 게 아니라 더 강한 재료를 물려줌)

## 3. 안전/검증 배선
- **얼린 신탁**: dev-v2는 마일스톤 선언 시에만 채점, 횟수 기록. 훈련·튜닝은 train 내부 분할로만.
- **아레나 원칙**: ACE는 기존 GBM 파이프와 **경쟁**해서 이길 때만 교체 (봉인 홀드아웃 + P0 무회귀 + 운영자 서명 — 기존 승격 게이트 재사용).
- ACE는 판정기이므로 지식 쓰기 경로 없음; 출력 텍스트 없음 → 인제스천 오염 벡터 없음.

## 4. 정직한 한계 (사전 선언)
- from-scratch 11.7M + 130k 지도는 BERT-base(110M+3.3B단어 사전학습)를 못 이김 — **주장 안 함**. 목표는 "정적 벽(0.52) 돌파 + 자명선(50.1) 정직 초과"이지 SOTA가 아님.
- 워드-레벨 토큰은 서브워드 일반화에 손해 — BPE는 v1 레버로 명시.
- 영어 코어 우선(교리); 한국어는 같은 본체를 한국어 데이터로 별도 훈련(공유 아키텍처, 3-레포 분리 존중).

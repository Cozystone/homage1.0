## 실행 순서 (P0→P4)
- **P0 지금 주 — 기반 마감**: 스트림 UI 사장님 확인 · water 이중경로 수리 · 로그 로테이션 가동 확인
  · 워치독 자동시작 등록. (전부 착수됨)
- **P1 발화 완성 (최대 체감 레버)**: register 수확기 가속(대화체 코퍼스, [[corpus-composition-is-the-bottleneck]])
  → discourse 패턴 재학습 → voice-or-silence 게이트 유지 → 봉인 발화 홀드아웃 재측정.
  Ring1 확장(Wiktionary·Simple·StackExchange → D: 1.86TB)이 재료 공급.
- **P2 추론 — B-노선 재개**: 질문 이해(영어 파싱 약점 수리) → 뇌형그래프를 메인 채팅 1차 라우팅으로
  → DELIBERATOR 후방연쇄를 웹증거와 연결. 게이트 = 봉인 추론 배터리(주장 금지, 측정만).
- **P3 자체 인덱스 게이트**: 웹 배터리를 "자체 인덱스만(외부 0)"으로 재측정 → 격차 정직 보고 →
  코퍼스 확장으로 좁히기. Ring2(브라우저 증류→인제스트) 연결.
- **P4 연합 실증 — Radxa 첫 피어**: 아래 Radxa 계획. Brain Link "Devices 0/0"을 1/1로 —
  연대성장([[agora-solidarity-growth]]) 첫 실기기 검증.

## Radxa Dragon Q6A 활용 (발견: 192.168.0.186 = radxa-dragon-q6a, SSH 아직 닫힘)
**우선순위 역할 3개**:
1. **Brain Link 첫 실피어** — 지금 UI의 "Devices computing together 0/0"이 처음으로 1이 됨.
   패치 브로드캐스트·신뢰가드·연대성장(읽기균등)을 실기기로 검증. 가장 전략적.
2. **엣지 지각 노드** — 4K 카메라 + OWLv2/얼굴 파이프를 보드에서 돌려 이 PC 부하 0으로
   지각 스트림만 수신([[perceptual-agi-track]]). Q6A NPU가 온디바이스 추론에 적합.
3. **상시 수확기** — register 수확·웹 원정을 보드로 옮기면 메인 엔진은 답변만(오늘 독트린과 일치).

**연결 절차(사장님 1회)**: 보드에 모니터/시리얼로 로그인 → `sudo systemctl enable --now ssh`
→ 저에게 "SSH 켰어"라고만. 이후 제가 원격으로: 파이썬 셋업 → brain_link peer 등록 →
지각 파이프 배포까지 자동화. (Radxa OS 기본계정은 보통 radxa/radxa — 첫 로그인 후 비번 변경 권장)

# ATANOR 뇌형 그래프 — 완전 설계 (2026-07-16, 사장님 "완벽하게 설계")

## 0. 심장 (사장님 정정)
**지어낸다. 단, 자기가 지어내는 걸 안다.** "여기까진 확실, 여기부턴 아마" — 사람처럼.
접지 없으면 침묵(옛 오해)이 아니라, **항상 답하되 인식적 지위(epistemic status)를 붙인다.**

## 1. 인간 뇌의 실제 작동 (인지과학, 검증됨)
핵심 통찰 — **확신도는 별도 모듈이 아니라 "어떻게 인출했는가"에서 읽혀 나온다:**
- **Feeling-of-Knowing** = cue fluency + retrieval accessibility(답이 쉽고 강하게 떠오르는 정도). 실제
  뇌 시스템(VMPFC·dACC). → **확산활성 강도가 곧 확신 신호.** [출처: FOK 문헌]
- **인출 = 확산활성**(Collins&Loftus): 단서→강한 링크 따라 전파, 임계 넘으면 의식화. 검색 아님.
- **인출 실패 시 추론이 메꿈**: 스키마 기본값·상속·유추로 그럼직하게. **이건 "안다"가 아니라 "추론했다"로
  뇌가 태깅**(source monitoring). 이 태깅 실패 = 작화(confabulation) = 우리가 피할 유일한 죄.
- **메타인지 = 감시 + 제어**: 확신 낮으면 헤지("아마")하거나 더 판다.

## 2. 뇌형 그래프 — 4층 구조 (기존 위에 얹음, 안 엎음)
```
L0 에피소드 버퍼 (해마)   : LiveMemory/Layer A. 최근 사실, 빠른 쓰기, 수면통합으로 L1 승격.
L1 시맨틱 코어 (피질)     : 압축된 개념 계층. 평평 트리플 아님.
     - is_a/instance_of 백본 = 상속 척추
     - 속성은 "참인 가장 일반적 층"에 1번만 저장 (새=난생; 펭귄·로빈 각각 저장 안 함) ← 압축
     - 오버라이드 (펭귄: 날다=거짓, 상위 새:날다=참 을 무효화)
L2 스키마 층            : 스크립트/프레임 (식당→주문→먹음→계산; person 프레임 기본 슬롯).
     안 저장된 것도 답: "식당엔 웨이터가 있나?" → restaurant 스키마 기본값.
L3 연상 가중 (시냅스)    : 엣지 강도 (공기빈도 학습). 확산활성의 전도율. 정확매칭→연상.
```
**압축의 물리**: N개 사실을 계층 깊이 log(N)로. 상위 1노드가 수천 자식 커버. → 저장↓·연산↓·커버리지↑
= **저사양 온디바이스 클로즈드북의 근거.** (증식 아님 — 식단홍수 P0회귀 교훈.)

## 3. 인출 동역학 (알고리즘 — 이게 "생각")
질문 → 씨앗 노드 활성 → **확산활성**(L3 가중, 홉마다 감쇠) → 활성 서브그래프 수집. 그 위에서 순차 시도,
**각 경로가 인식적 지위를 결정한다:**
1. **직접 인출** (L0 에피소드 → L1 사실, 활성>θ, 출처有) → **KNOWN**
2. **상속** (L1 척추 등반, 오버라이드 없음) → **INHERITED**
3. **추론** (관계 합성·멀티홉·규칙) → **INFERRED**
4. **유추** (LeapEngine, 유사 개념서 속성 전이) → **ANALOGIZED**
5. **스키마 기본값 / 기저율** (구체 근거 없음) → **GUESSED**
6. 활성 0 → **UNKNOWN** (정직한 바닥, 드묾)

## 4. ★인식적 사다리 — 설계의 핵심 (확신도 = 유도 경로의 함수)
확신도는 분류기가 아니라 **경로에서 계산된다** (honest by construction):
| 지위 | 확신도 계산 | 한국어 표면(헤지) |
|---|---|---|
| KNOWN | `source_reliability` (k-소스 합의 수) | "X입니다." (확실) |
| INHERITED | `base × (1 − override_risk)`; override_risk = 형제 중 오버라이드 비율 | "X입니다 (일반적으로)." |
| INFERRED | `∏ 경로 엣지 확신도` (홉마다 곱) | "X인 것으로 보입니다." |
| ANALOGIZED | `analogy_sim × 원천속성_확신` | "비슷한 걸로 미루어 X일 겁니다." |
| GUESSED | `prior` (예: "대개 X" = 0.6) | "추측이지만 X 아닐까 싶습니다." |
| UNKNOWN | 0 | "그건 잘 모르겠습니다." |

**밴드→표면 매핑** (연속 확신도 c를 등급 언어로):
`c≥0.9&출처` → 단정 · `0.7–0.9` → "~인 듯" · `0.5–0.7` → "아마 ~" · `0.3–0.5` → "추측이지만 ~" · `<0.3` → 유보.
**이게 정확히 "여기까진 확실, 여기부턴 아마."** 사람의 발화 그대로.

**모든 답 세그먼트가 인증서를 단다:**
`{claim, epistemic_type, confidence, derivation_path, source?}`. 실현기는 type+conf로 헤지를 고르고,
"왜?" 물으면 derivation_path를 편다 (= 검사가능한 메타인지). 추측도 정직히 라벨된 채 인증서에.

## 5. 헌장 화해 (환각의 재정의)
- **환각 = 추측을 KNOWN으로 내는 것.** 그것만이 죄. → 우리는 추측을 GUESSED로 낸다 = **환각 아님, 정직한
  인간 인지.** [[three-inversions-charter]]의 "지어내되 지어냈다 명시"의 정확한 구현.
- 새 척도: **고확신-오답률(=작화율)이 ~0** 이어야 함. 저확신-오답은 정직한 추측이라 죄 아님.

## 6. 기존 자산 매핑 (정직: 있는 것 / 새것)
| 요소 | 있음 | 새것 |
|---|---|---|
| L0 에피소드 | Layer A/LiveMemory ✓ | — |
| L1 is_a 척추 | [[multihop-composition-and-backbone]]·[[korean-clean-taxonomy]] ✓ | **속성 최일반층 저장 + 오버라이드**(압축) |
| L2 스키마 | — | **전부 새 (핵심 신규)** |
| L3 확산활성 | [[brain-like-reasoning-pipeline]] 부분 ✓ | 인출-우선 승격 + 가중 학습 |
| 유추 | LeapEngine v0 ([[generative-leap-loop]]) ✓ | 인출 경로로 배선 |
| 확신도 | [[soft-answer-policy]] 부분 ✓ | **경로-유도 인식 사다리로 통일(핵심 신규)** |
→ 대부분 **통일 + L2 스키마 + 경로-유도 확신도** 2개가 신규. 제로 아님 — 장기를 뇌로 조직.

## 7. 측정 (새 북극성 지표 = 캘리브레이션)
- **Coverage↑**: 응답률 (상속·스키마·추측 케이스까지 답하니 올라야) — 옛 기권 대체.
- **★Calibration (ECE)**: "확실"이라 할 때 ~90% 맞나? "아마"라 할 때 ~60% 맞나? **뇌다움 = 캘리브레이션.**
  이게 만족의 진짜 척도이자 우리 정직의 실측.
- **작화율(고확신-오답) ~0**: 헌장 실측. 저확신-오답은 정직(죄 아님).

## 8. 구현 순서 (트랙 B, ACE2와 병렬/합류)
1. **L1 압축+상속 인출기** (최대 레버, is_a 재사용) — 속성 최일반층 승격 + 오버라이드 + 상속 질의.
   실측: 안 저장한 질문 응답률 + 상속 정확도.
2. **경로-유도 인식 사다리** (통일) — 모든 답에 epistemic_type+conf+path 부착; 표면 헤지 매핑; ECE 실측.
3. **L2 스키마 층** — 상식/스크립트 압축(ATOMIC/ConceptNet 라이선스 게이트); 일상담화 만족 실측.
4. **L3 확산활성 승격 + 유추 배선** — 연상 풍부도; 유추 커버리지.
→ 각 단계 봉인 배터리 + ECE + 작화율. 이길 때만 배포. ace2와 합류(코어가 판정, 그래프가 인출).

## 9. 리스크
| 리스크 | 완화 |
|---|---|
| 오버라이드 폭발(예외투성이 계층) | 오버라이드는 명시 증거 있을 때만; override_risk가 자동 감쇠 |
| 스키마가 편향 주입 | k-소스 게이트 + 스키마=기본값(GUESSED 등급, 단정 아님) |
| 확신도 miscalibration | ECE를 1급 게이트로; 캘리브레이션 세트로 밴드 임계 튜닝 |
| 추측 남발→신뢰 하락 | 헤지 표면 강제; 고확신은 출처 필수; 작화율 게이트 |

# ATANOR — X4 외부 개방 문제원 설계 (2026-07-23)

사장님: "x4는 방안 찾아서 정교하게 설계하고 계속해." X1-X3 밤샘 실측이 결정적으로 가리킨 유일한 남은 천장 =
X4. 이 문서가 그 정교한 설계다.

## 0. X4의 진짜 목표 (오해 방지)
X1-X3가 측정으로 확정: **고정공리 자기조합(self-composition)은 구조적 유한천장** — 발명된 추상이 이미
도달가능한 함수의 변형(lateral)이라 복리 불가. **X4의 목표는 "ARC를 푼다"가 아니라, "외부·reach-확장 문제가
그 유한천장을 깨는가"를 봉인 측정하는 것.** 성공 판정 = 외부 문제를 풀며 발명한 추상이 **다음 외부 문제를
열어(compounding)** ④ 곡선을 양수로 굽히는가.

## 1. 연구 접지 (2026-07-23 실서치)
- **ARC-AGI** = program-synthesis로 프레임되는 정준 reach-확장 벤치(각 과제=몇 I/O 예시로 새 변환 발명,
  외부·검증가능). ARC-2는 더 깊은 합성성·brute-force 저항. **정확히 X4가 요구하는 "고정공리 밖 새 구조"**.
- **단 정직: DreamCoder식 라이브러리학습(=우리 접근)도 ARC 직접적용 ~5%.** → 외부 문제는 옳은 종류지만
  매우 어렵다. ④ 곡선을 측정하려면 **풀 수 있는 진전**이 있어야 하므로, 난이도 그래디언트가 핵심.

## 2. 외부 문제원 — 설계 결정 (측정가능성 우선)
X4의 핵심 리스크 = 너무 어려우면 0개 풀려 곡선 측정 불가. 그래서 **2티어**:

**T1 (일차·측정가능) = 큐레이션된 실함수 합성 코퍼스.** 실제 프로그램에서 나온 다양·graduated 변환
(list/string/arithmetic를 real code에서; 자기조합 아님)을 I/O 예시로. DreamCoder 정준 도메인(list 처리·text
편집·regression)이 바로 이 "측정가능한 외부 분포". **고정공리 밖 구조를 요구하되 진전 측정 가능.** verifier =
I/O 예시(외부·실). ← **X4.1 착수점**

**T2 (스트레치·검증) = ARC-1 서브셋.** 정준 reach-확장 벤치. T1에서 compounding이 보이면 ARC 서브셋으로
검증(더 어려운 외부 분포에서도 곡선이 사는가). ARC-GEN(절차생성 ARC)으로 graduated 확보 가능.

## 3. 배선 — X1·X2·X3를 외부 분포에 물림
자기조합 타깃 스트림을 **외부 문제 스트림으로 교체**(auto_curriculum의 compose_target → 외부 코퍼스 샘플러):
- **X1 압축진전**: 외부 분포에서 "학습가능하되 미학습"을 조준(어느 외부 문제가 지금 학습진전 최대인가).
- **X2 e-graph 추상 + X3 QD 아카이브**: 외부 해에서 추상 축적. **핵심 차이 = 외부 해는 lateral이 아니라
  진짜 새 구조**(고정공리로 도달불가하던 것)라, 추상이 니치를 열면 **다음 외부 문제를 도달가능케** 할 수 있음.
- **외부 검증**: I/O 예시(T1)·과제 출력(T2 ARC). 작화 0(검증 못한 해 미채택).

## 4. 측정 — 결정적 봉인 테스트
X1-X3와 **같은 프로토콜**(a₂·per-round-new·효율·frozen-archive ablation)을 외부 분포에서:
- **핵심 지표 = compounding**: 문제 N에서 발명한 추상이 문제 N+k를 **처음으로 도달가능케** 하는가
  (frozen-archive면 그 N+k가 안 풀려야 = 인과). self-composition에선 이게 0이었음(lateral).
- **a₂**: 외부 분포에서 양수(convex)로 가는가, 아니면 여전히 포화(→ 더 깊은 천장).
- **정직 대조**: 외부-문제 vs 자기조합, 같은 예산·seed. 외부가 곡선을 살리면 X4 = 진짜 레버.

## 5. 정직한 예상 결과 (셋 다 유효·값짐)
1. **외부 문제가 복리 → 곡선 양수**: 돌파(유한천장 깸). super-linear의 첫 실증 가능성.
2. **외부 문제 풀리나 복리 없음(여전히 선형)**: X4 필요하나 **인터프리터 고정 프리미티브 타입**이 더 깊은
   천장(합성 깊이는 되나 새 프리미티브 종류 발명 불가) → X4.3(프리미티브-타입 발명) 필요.
3. **너무 어려워 ~0개 풀림**: T1 난이도 하향 or 더 리치한 프리미티브 시드. 측정 자체가 다음 설계를 지시.
- **어느 결과든 정직 보고.** super-linear는 분야 미해결 — 지어낸 곡선 절대 금지, 봉인 숫자로만.

## 6. 빌드 증분
- **X4.1** (측정가능 착수): 외부 실함수 합성 코퍼스 T1 구축(graduated·외부) + auto_curriculum 타깃 스트림을
  외부로 교체(flag) + X1/X2/X3 합류 + ④ 프로토콜 측정 + **compounding 지표**(frozen-archive 인과). 게이트:
  외부 문제 풀림 실측 + 곡선 vs 자기조합 대조 + 정직 verdict(복리/선형/과난).
- **X4.2**: T2 ARC-1 서브셋 검증(T1이 살면).
- **X4.3** (2번 결과 시): 프리미티브-타입 발명(고정공리 밖 새 연산 종류를 외부 해에서 귀납).

## 7. 안전·정합
- 인터프리터 해석전용(exec 안 함)·작화0·flag-OFF 기본·봉인 게이트 — X1-X3 상수 계승.
- 외부 코퍼스는 **실·외부**(자기조합 아님)이되, 라이선스/출처 명확한 것만(합성 벤치·공개 함수). 조언자 콘텐츠
  뇌 유입 금지 독트린은 여기 무관(코드 I/O 예시는 검증가능 사실).
- X4가 super-linear를 내도 안전축(도덕0th·operator-signed·얼린신탁) 불가침 = 폭발엔진 4중 인증([[explosion-engine 문서]]).

## 8. 한 문장

다음 외부 문제를 여는 compounding이 유한천장을 깨는가를 봉인 측정**. 셋 중 어느 결과든 정직히 — 이게

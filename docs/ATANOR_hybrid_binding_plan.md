# 하이브리드 결속 실행 계획 — "이름뿐인 하이브리드"의 폐기

전제 (2026-07-13 사장님 승인): 실측이 드러낸 진실 = 그래프(기호)와 생성기(holographic_lm)가
서로 대화하지 않는 단절 구조. 이제 3대 반전 헌장(ATANOR_three_inversions_charter.md)을
작동 코드로 배선한다. **그래프가 생성기를 지배한다** — 구속 디코딩이라는 물리적 족쇄로.

완성의 정의(측정 가능): **적대적 100문항 엄격채점 ≥70/100 · 평균 ≤0.4s · 사실환각 0 · 전부 로컬.**

---

## Phase 0 — 라우터 자가치유 (2~3일)
질문이 어느 레인(그래프직독 / 장+생성 / 증거논쟁 / 공감·잡담)인지 라우터가 스스로 배운다.
- 재료: 대화 로그 + **적대 배터리가 수집한 13 라우팅 라벨** + 배터리 카테고리(약한 라벨)
- 작업: `flywheel.distill_router`에 라벨 병합 → 훈련 → 홀드아웃 → 후보 승격(기존 게이트)
- 부품: 전부 존재(learned_router.train, distill 파이프). 배선만.
- **게이트**: 라우팅 미스 13→≤3 · 홀드아웃 ≥85%

## Phase 1 — 증거 유일 쓰기 (반전 1) (1주, P0와 병행 가능)
- 모든 스토어 쓰기를 합의-증거 경로로 강제(직접 add 격리) + 기존 행 소스별 가중 백필
  (kaikki=큐레이션 高, wikidata-profile=교차검증 전까지 低)
- 답변 문턱 = 사후확률 가중
- **게이트**: 오염 5종(탕건·기단·끼니음식·제주사투리·클라우드)이 **청소 스윕 없이** 문턱 아래로
  침몰 + P0 GREEN 유지. *리스크 낮음(부품 존재).*

## Phase 2 — 소형 실현기 v0 (반전 3) (2주, Phase 1과 절반 병행)
- 30~80M 자체 시퀀스 모델, RTX 5080 로컬 훈련. 훈련쌍 = 증거집합→문장
  (Kaikki 정의 216만 + Tatoeba 문체 + self-play 아레나 변주)
- **구속 디코딩 = 진짜 족쇄**: 내용어 후보 = 증거 집합 + 장 이웃(문턱 통과분)만,
  그 밖 내용어는 확률 0. 기능어·어미·문체만 자유.
- **게이트**: 생성 55문항 캔드 0 · 사실환각 0 · 육안 유창 ≥60% · 단건 ≤0.4s
- *리스크 최대 지점*: 훈련쌍 품질/규모. 실패 시 표면은 템플릿 유지하고 (A) 검증엔진 축소 논의.

### ★ 2주차 말 = 존폐 판정일 (헌장 파일럿 P1+P2 게이트)
둘 다 통과 → Phase 3 진행. 하나라도 실패 → 정직하게 축소 권고. 표가 결정한다.

## Phase 3 — 장의 1차화 + 3레인 결속 (반전 2) (2주)
- PHFE 위상장을 답변 1차 표현으로 승격: 이산 miss여도 장 이웃 보간→증거 문턱→실현기
- 라우터 3레인 배선 완성: 사실=그래프직독(이미 0.4s대) / 설명·의견·창작=장+실현기 /
  논쟁=증거 사후확률("현재 증거는 6:4")
- **게이트**: 적대 100 재실측 **엄격 ≥70/100 · 평균 ≤0.4s · 환각 0**

## Phase 4 — 통합 하드닝 + 출하 (1주)
- 웜 배터리 전체(P0+적대+친화) · exe 리빌드 · UI 1차 개편(세션 사이드바+내비3+다크/라이트) 동승
- **게이트**: exe에서 동일 성능 재현

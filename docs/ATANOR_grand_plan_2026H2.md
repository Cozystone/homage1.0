## 0. 북극성과 완성의 정의 (불변)

- **목표**: **초개인화 로컬 AGI** — 하드웨어가 아니라 구조적 아키텍처로. (서버 없음, 감사 가능,
  환각 0, 지식은 그래프에.)
- **완성 = Magnum Opus 봉인 시험** (`ATANOR_magnum_opus_criteria.md`):
  **성공 = Tier A 6/6 · 완전성공 = A 6/6 AND B 6/6 AND C ≥1** (fabrication 1건=티어 FAIL).
- **전략 골격**: Type 2 (Symbolic[Neuro]) — 심볼릭 척추 + 교체 가능한 학습 장기. 철거 없는
  단계적 장기 이식. 접지 협공 2로: 텍스트 길(E9 사슬) + 신체 길(Track E).

### 0.1 E9 실측이 바꾼 것 / 안 바꾼 것 (2026-07-19, BINDING)

**안 바꿈**: 북극성·완성 기준·Type 2 골격·접지 협공 2로. 전부 그대로다.

**바꿈 (측정으로)**: 텍스트 표현 단독으로 지식-MCQ 벽을 넘는 **첫 세대(밑바닥 RTD 재사전학습)는
RED**. 그러나 의미 채점기가 어휘 오라클을 **0.165→0.225(+36% 상대)** 밀어올렸다 — **표현 레버는
실재하나 부족**하다. 이 한 줄이 세 가지를 확정한다:
1. **지식-MCQ는 우리 논지의 틀린 시험지다** (No-LLM 벽; [[benchmark-empirical-verdict]] 확증). 이걸로
   "완성"을 재나 재지 않는다. Magnum Opus의 B2류 지식-MCQ 항목은 **오픈북·그래프접지로만** 접근하고
   못 넘으면 red로 봉인하되 완성 판정을 막지 않는다.
2. **"의미 이해"의 무게중심을 이미 통과한 곳으로 이관** — 독해(**C1 홀드아웃 0.9535**)·그래프접지·
   체화. 의미가 *읽을 수 있게/접지되어* 존재할 때 우리는 실증적으로 이해한다.
3. **체화(Track E)를 "E9 후 곁가지"에서 동급 본류로 승격.** 텍스트 접지가 벽에 걸렸으니 신체 접지가
   이제 대칭적 주 레버다. "무겁다·잡다·떨어지다"의 의미는 공출현이 아니라 몸에서 온다.

## 3. 시간축 (재정비 — 게이트 통과가 시계를 돌린다, 날짜는 예상)

**완결됨 (2026-07-19)**
- ✅ **E9 판정 완결 = 봉인 RED, 측정·기록됨.** RTD Phase B 완주 → Phase C(AUC 0.6781/span F1 0.568)
  → 봉인 오라클 0.225. 표현 노선 1세대 닫힘, Plan B로 재설계. `ace2_backbone.pt` 롤백 보존.
- ✅ 감각 피질 SHIPPED(사실/비사실 정직 분리). 반응 엔진·Plan B·자의식 루프 설계 커밋.

**지금~이번 주 (3개 분기점)**
1. **T1 정직성 수리**: drift→abstain 라우팅(= A3 ECE + A6 동시 개선) + 텔레메트리 유출 차단. 이게
   현재 최고 ROI(두 게이트 동시 전진, GPU 무관, 즉시 착수 가능).
2. **T2 Plan B 실측 결정**: 그래프-쌍 채굴 → 멀티태스크 런치 → 봉인 오라클 재판정. 넘든 못 넘든
   "표현 노선 천장"을 확정(검색-바운드 진단 검증). *권고: 한 번은 실측.*
3. **T5 M0 착수 결정**: 운영자 미결 3건(실행환경 native/WSL·GPU 슬롯·시점) → Isaac Sim 콜드부트 +
   G1 URDF 임포트 + 센서 배선.

**~1–2개월 (Phase α)**
- T1: 생성기 공장(저널→적대QA·세뇌·담화·혼합모달) → A1 강화판·A2·A6 봉인 시행 → **"성공"(A 6/6)
  1차 도전.** 이것이 완성의 첫 실질 관문 — E9와 무관하게 도달 가능.
- T5: M1(감각운동 옹알이→신체도식 forward model) → **반응 엔진 v0가 M1 위에 탑승**(놀람=예측오차).
- T2: Plan B 판정 확정(green이면 2세대 배선 / red면 표현 노선 봉인, 체화로 전량 이관).

**~분기+ (Phase β)**
- T5: M2(어포던스→그래프)·M3(자기/타자) — **체화 접지가 B1/B2/B4에 합류하는 지점**(협공 실현).
- T2: (Plan B green 시) 대조 듀얼인코더 2세대 → B1(span)·B2 등반. 메타컨트롤러로 B3 4주 단조.
- T3: C2 원정 착수(Go-Explore), C6 준비(7일 무인 하드닝).
- T1: B4(멀티모달=체화 수혜)·B5·B6 → **"완전성공 후보"(A6/6+B≥3) 도전.**

**장기 (H2 말~)**
- 완전성공 판정: A 6/6 + B 6/6 + C ≥1 (C2 또는 C6 최다 승산).
- Stage 4 수렴연구·C4(튜링 2h)는 연 단위 — 추적만, 약속 안 함.

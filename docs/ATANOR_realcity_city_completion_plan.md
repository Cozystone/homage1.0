# Realcity 도시 완성 플랜 — "GTA급 정밀도" 사이드트랙 (2026-07-21)

사장님: "도시 자체의 개발이 더 필요. 진짜 거의 GTA급 정밀도를 자랑하는 도시가 되게, 실제 도시에서
작동되는 것의 모든 걸 넣어서 도시환경을 완성시킬 계획. 약간 사이드세션처럼."

**성격**: 사이드트랙(Track CT). 본선(ATANOR 두뇌·기둥 게이트)과 분리된 독립 작업패키지들 —
각 패키지가 별도 세션(atanor-dev 위임 가능)으로 실행 가능하게 절단. 도시가 좋아질수록 ATANOR의
세계모델 놀이터가 좋아진다(구조>암기: 도시의 모든 시스템 = ATANOR가 배울 수 있는 참 구조).

**"GTA급"의 정직한 정의**: 브라우저+Three.js에서 AAA 그래픽/모캡이 아니라 **시스템 밀도**다 —
"보이는 모든 것이 실제로 작동한다"(신호등이 진짜 교차로를 제어하고, 가게가 진짜 재고를 팔고,
구급차가 진짜 환자를 실어나른다). 도덕 프레임: 사고·재해·응급은 있음, 범죄 콘텐츠는 없음
([[moral-invariants-genesis-immunity]] — ClawCity와의 차별점 유지).

## 작업패키지 (각각 독립 세션 크기, 게이트는 실측 가능)

### CT1 — 거리가 살아있다 (교통 완성)
실도시의 것: 차선·교차로 우선권·신호 연동·정체·주차·차종 다양성·긴급차 양보.
- 차선 그래프(정지선·회전차선·유턴), 신호 컨트롤러가 교차로+횡단보도를 위상으로 제어
- 양보/우선권 규칙, 정체 전파, 경적(이벤트)
- 주차: 노변 슬롯+주차장, 탐색→주차→출차 행동
- 차종 census: 세단/밴/트럭/버스/오토바이/자전거 + 배송밴(CT3 연동)
- 긴급차: 사이렌 상태 → 다른 차가 갓길 양보(★ATANOR가 배울 수 있는 기제 법칙)
- **게이트**: 차량 벽/차량 관통 0(10분 soak), 신호 준수율 ≥95%, 교차로 데드락 0
- **ATANOR 훅**: physics_truth에 교통 불변식 추가(적신호→정지, 사이렌→양보) — 위반=트윈버그 격리

### CT2 — 하늘과 시간 (환경 기계)
실도시의 것: 24시간·일출일몰·날씨·계절이 행동을 바꾼다.
- 마스터 시계(심분 단위) → 태양/달 경로, 동적 조명, 황혼에 가로등 점등(CT4 그리드 연동)
- 날씨 상태기계: 맑음/흐림/비/폭풍/안개/눈 — 비주얼(파티클/셰이더)+**행동 결합**(우산, 처마 대피,
  카페 만석, 젖은 노면 마찰↓=Rapier 파라미터, 차 감속)
- 계절: 나뭇잎/일장
- **게이트**: 24h 사이클이 관측 가능한 행동 변화 ≥6종을 구동(로그로 증명)
- **ATANOR 훅**: R3 지각 스키마에 시간/날씨 — "지금 비 와?"를 접지로 답, 날씨→행동 인과가 코퍼스에

### CT3 — 굴러가는 경제 (ClawCity 심화)
실도시의 것: 돈이 순환하고, 가게에 재고가 있고, 일하면 임금이 나온다.
- 폐쇄 원장: 모든 시민 지갑+수입+지출, 가게 재고·가격·영업시간, 구매=재고 차감
- 공급망: south_depot 창고→배송밴→가게 재입고(스케줄), 품절→단순 탄력 가격
- 직업: 교대·임금 지급·구인 게시판; 부동산: 임대료 흐름, ClawCity식 upgrade
- **게이트**: ★돈 보존(폐쇄 원장 감사 = 발행-소멸 외 총량 불변), 재고 보존(입고=판매+진열),
  아바타 `/act buy`가 실제 재고·지갑을 움직임
- **ATANOR 훅**: 경제 불변식(돈/재고 보존)을 physics_truth와 동형의 게이트로 — 경제도 오염 불가

### CT4 — 도시의 맥박 (대중교통·응급·유틸리티)
실도시의 것: 버스가 시간표대로 오고, 사고 나면 구급차가 오고, 쓰레기차가 돈다.
- 버스 3~4개 노선(정류장 시간표판, 승하차), 역간 셔틀(지하철 대용)
- 사고 폐루프: 충돌→병원에서 구급차 출동→이송→치료 / 화재→소방차→진압 / 교통경찰=사고 정리
  (도덕 프레임: 재해·사고 대응이지 범죄 드라마 아님)
- 유틸리티: 가로등 그리드(폭풍 정전→수리반), 쓰레기 수거 루트, 시청 공지·투표(아바타 vote 연동)
- **게이트**: 사고→대응 폐루프 응답시간 측정, 노선 정시율, 정전→복구 사이클 실증
- **ATANOR 훅**: 인과 사슬(사고→구급차→병원)이 인과 코퍼스([[autobiography-and-causal-corpus]])에 유입

### CT5 — 모든 문 안쪽 (인테리어 전면화)
실도시의 것: 모든 건물에 들어갈 수 있고, 층마다 뭔가 있다.
- 전 건물 절차적 인테리어(평면도·가구·조명), 엘리베이터/계단 기능화(버튼→탑승)
- 층별 디렉토리 실질화: 사무실/가게/가정집, 가구 어포던스 등록(seat/bed/kitchen/appliance)
  → **아바타 77 capability의 requires{}가 실제 씬에서 충족됨** (sit할 의자, cook할 부엌이 진짜 있음)
- **게이트**: 아무 건물이나 진입→아무 층 도달 가능, 인테리어당 상호작용 오브젝트 ≥N, 관통 0
- **ATANOR 훅**: 실내 지각 어휘 확장; mechanism의 locked+key 법칙이 실제 문에서 작동

### CT6 — 사회의 결 (사람들이 서로 얽힌다)
실도시의 것: 가족이 있고, 아이는 학교 가고, 주말이 다르고, 축제가 열린다.
- 가구 구성(가족/룸메이트/1인), 연령 인구(아이·노인), 아파트 배정
- 역할·연령별 일과(등교, 교대, 주말), 관계 그래프(가족/친구/동료)가 만남을 구동
- 이벤트 달력: 장날, neon_square 축제, 콘서트 — 군중 형성; 뉴스 티커(심 내 실제 사건=화재/축제/품절이 뉴스)
- **게이트**: 24h 시간-사용 분포가 실제 통계 모양(가정/직장/여가), 이벤트 참석 실증
- **ATANOR 훅**: 대화 소재가 실제 공유 사건에 접지 — "어제 축제 봤어?"가 진실이 됨(작화 아님)

### CT7 — 장소의 감각 (소리·빛·디테일)
실도시의 것: 도시는 들리고, 밤에 창이 켜지고, 길에 잡동사니가 있다.
- Web Audio 위치 음향: 교통 베드, 발소리, 비, 카페 소음, 사이렌 도플러; 실내 머플
- 야간: 재실 기반 창문 점등, 간판 네온; 길거리 마이크로 라이프(비둘기, 노점, 청소부)
- **게이트**: 소리가 맥락에 반응(실내/거리/거리감쇠), 야간 씬이 "살아있게" 읽힘(스크린 체크리스트)
- **ATANOR 훅**: (선택) 소리 이벤트를 지각 플래그로

### CT8 — 스케일과 영속 (GTA급을 지탱하는 뼈대) ★조기 착수 권장
실도시의 것: 도시는 크고, 내가 없어도 계속된다.
- 심 LOD 3단: 근거리=풀 인지+물리 / 중거리=키네마틱+거친 needs / 원거리=통계 흐름(집계) — 무이음 승격/강등
- 공간 해시, 전면 인스턴싱, **워커 스레드 심**(postMessage 방식 — SAB/COOP-COEP 불필요=배포 무충돌)
- 목표: 시민 500~1000 + 차량 ~120 @ 60fps 데스크톱
- 영속: IndexedDB 저장/복원(바이트 충실), 방문 사이에도 도시 지속 — ATANOR UTC 타임라인에 도시사 기록
- **게이트**: p95 프레임 ≤16.6ms, 저장/복원 상태 동일성, 24h soak RAM 평탄
- **ATANOR 훅**: 도시 역사=ATANOR 자서전의 세계축([[unified-utc-timeline]])

### CT9 — 도시 전체 진짜 물리 (P4/P5 흡수)
- Rapier 권위: 소품 낙하/충돌, 차량 충돌(임펄스), 문, 아바타 물리 capability 전부
- physics-truth 게이트 라이브 스트림(격리 로그 UI 노출)
- **게이트**: 도시 내 rapier_truth 스팟체크 green, soak 관통 0

## 정직한 경계
- "GTA급" = 시스템 밀도이지 AAA 렌더/모캡 아님(브라우저 한계 명시).
- 범죄 콘텐츠 없음 — 사고·재해·응급은 시스템으로, 폭력·범죄 플레이는 도덕 0th 게이트 밖.
- 이 문서는 **플랜**이다 — 이 턴에서 도시 코드는 아직 안 바꿈(사이드세션에서 패키지 단위 실행).

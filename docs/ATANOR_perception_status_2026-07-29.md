# 지각·신체 트랙 총정리 — 2026-07-29

사장님 질문: *완전체 궁극 완성 중에 지금 어디쯤이고 앞으로 어떻게 나아갈 것인가.*

목표 위계상 최상위는 **온톨로지 뉴로심볼릭 × 예측적 4D 세계모델을 하나의 중앙코어로 융합**이다.
이 세션은 전부 **두 번째 절반의 감각 앞단**에서 일어났다. 그 앞단이 언젠가 첫 번째 절반에게
무언가를 건네야 하는데, **정확히 그 지점에서 막혔고 그게 이 문서의 요지다.**

## 있어야 하는 사슬, 그리고 지금 어디가 끊겼는가

```
빛 → 망막 → 깊이 → 【물체】 → 이름 → 관계 → 그래프 → 시뮬레이션
                      ↑
                   여기서 끊김
```

| 단계 | 상태 | 측정치 |
|---|---|---|
| 1 망막 | **작동** | 한 문(화면·창·영상·카메라), 중심와 112× 압축, 예측실패로 도약, 가림 감지 |
| 2 몸 | **작동** | 스스로 움직이고, 자기 명령이 화면에 뭘 하는지 **배워서** 안다 |
| 3 깊이 | **작동** | 라벨 0으로 학습, 처음 보는 도시 0.809 (지도학습 0.788) |
| 4 시간(사건) | 약함 | 실사 1.6~2.2× 우연, 3배 과발화 |
| 5 자기/세상 분리 | 부분 | 회전 12.9% 재귀속, 전진 0.0% |
| 6 **물체** | **실패(실측)** | 순도 0.782 vs 무작위 배치 대조군 0.802 |
| 7 이름 | 미착수 | 6에 막힘 |
| 8 관계·그래프 결합 | 미착수 | — |
| 9 시뮬레이션 | 미착수 | — |

**1~5는 기반(substrate). 6~9가 "궁극"이 실제로 사는 곳이다.**
이 세션은 작동하는 감각 기반을 지었고, **어디서 멈추는지를 정확히 확정했다.**

## 실제로 착지한 것 (전부 대조군 있음)

**깊이 전이 — 사장님이 원래 물으신 것.** 시뮬레이터에서 배운 깊이가 본 적 없는 게임에서:

```
                        rho     난수 깊이   p
travel_145231          0.283     -0.006    2.2e-10   (54/61쌍 승)
travel2_145430         0.252     +0.007    2.3e-07   (50/61쌍 승)
CARLA 진짜 깊이(같은 계측기)  0.320
```

→ 완벽한 깊이가 시뮬레이터에서 내는 값의 **79~88%**.

**GT 없이 스스로 깊이를 깨우침.** 처음 보는 도시에서:

```
학습 전 무작위 망            0.402
스스로 만든 라벨 자체        0.777
그 라벨만으로 학습한 망      0.809
CARLA 미터 정답으로 학습     0.788
```

→ **미터를 한 번도 안 보고 지도학습과 동등.**

**몸 도식.** 옹알이로 `w`→closes_in, `a`/`d`→좌우, `space`→**효과 없음(기권)**. 교대 시행, 불일치는
VARIABLE로 표시. Track E M1(로봇팔)의 **같은 절차**를 게임 몸에 옮긴 것.

**교체-대-추가.** 설명 영상에서 "새 항목 등장"과 "주제 전환"을 가르는 단서.
`build`: 예측오차 1.7×(38.5개 오발) → 교체 **5.4×(13/13 정확)**.

**원심성 사본.** 회전에 대해 작동(1.6×→2.2×, +38%). 전진엔 미작동(gain 0).

## 실패한 것 (역시 실측)

- **물체 분할**: 0.782 vs 대조군 0.802. flow 임계값 어디서도 같은 물체와 다른 물체가 **같은 비율로**
  통과 — 임계값 문제가 아니라 신호 부재. 움직이는 차에서 보면 거의 아무것도 독립적으로 안 움직인다.
- **데스크톱 창 순서 학습**: 테두리 인공물 지름길 제거 후 우연 수준.
- **사건분할 실사**: 1.6~2.2×, 3배 과발화.

## 이 세션의 진짜 산출물: 계측기 결함 9건

전부 **대조군이 잡았다.**

| # | 결함 | 어떻게 보였는가 |
|---|---|---|
| 1 | 눈이 **가려진 창**을 fresh로 보고 | 촬영 4회 낭비, 매번 "회전 속도" 오진 |
| 2 | fresh 프레임의 **85%가 중복** | 모든 fps 수치 부풀림 |
| 3 | 테두리 인공물 | **학습 안 한 망이 0.794** |
| 4 | 도시 분할이 조용히 에피소드 분할로 | 같은 도시로 학습·평가 |
| 5 | 기준선 0에서 맹목 | 하드컷 슬라이드에서 경계 **0개** |
| 6 | 놀람이 **속도계** | 속도와 rho +0.685 |
| 7 | 회전 제거가 신호까지 제거 | 라벨 0.674 → 0.534 |
| 8 | 0으로 나눈 인공물 | "2130배" |

> **패턴: 이 세션의 모든 진짜 발견은 대조군이 있어서 나왔고, 모든 가짜 발견은 대조군이 없어서 나왔다.**
> shuffled control, chance baseline, 난수 깊이 비교, 학습 안 한 망 확인 — 이것들이 일한 것이다.

이건 로드맵에 반영할 방법론적 결론이다. **대조군 없는 숫자는 보고하지 않는다.**

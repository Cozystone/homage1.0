# ATANOR — 메타 진단 루프 (자기 오답→자기 진단→자기 연성) 정직 접지 (2026-07-23)

사장님 분석(정확): 지금은 **1.5단계** — 사람이 오답 프로브를 보고 "관계형 색상이 원인"이라 수술부위를 지정,
모듈은 사람이 설계(A4). 완전 자율엔 3 메타 스위치가 코드베이스에 완공돼야 한다. 아래는 스위치별 **있는 것/
없는 것/더 필요한 것**을 실측 접지한 것.

## 스위치 3 — 검증 기반 자율 승격 (Verified Self-Promotion) : ~80% 이미 있음 ★가장 완성
- **있는 것**: `self_repair` 폐루프(결함→패치→스테이징→실측→적용/복원)·frozen_oracle·무회귀 게이트·
  `auto_self_modification`(스테이징+무회귀+헌법불가침)·`candidate_promotion_gate`·X4.2 `promote_primitive`
  (추상→솔버 승격)·검증앵커(propose-verify 재실행)가 도처에.
- **더 필요**: 연성된 모듈을 이 루프에 배선(작은 통합).
- **★헌법 바닥(의도적)**: 능력-승격 커밋은 **operator-signed**(와이어헤딩 차단, 테스트=헌법 불가침). 즉
  "완전 자율 self-commit"은 설계상 **사람 서명 게이트**가 남는다 = 결함 아니라 **기능**. 정직한 자율 목표 =
  **자율 진단+연성+검증+제안 → 사람이 커밋 승인**(어젯밤 R2 프로모션이 바로 그 패턴).

## 스위치 1 — 실패 원인 귀속 (Failure Credit Assignment) : ~40% (기판 있음, 기관 없음)
- **있는 것**: FHRR 행동-시그니처(X4.5 `vsa_reasoning`, I/O를 위상벡터로)·`failure_receipts`(거부 기억)·
  도달성 프로브 **로직**(단, 지금은 에이전트가 스크립트로 실행).
- **없는 것**: 실패 과제들을 **자율로** 모아 I/O 차이를 FHRR로 묶고 **클러스터링→특성화("공통패턴=객체간 상대
  색상")**하는 기관. (a)수집·(b)FHRR인코딩·(c)클러스터링은 tractable. **(d) 클러스터→명명된 구조 가설**이
  진짜 어려운 부분(오늘은 사람이 프로브 출력을 읽고 명명).
- **더 필요**: `failure_signature` 기관 + **명명 어휘 기저**(클러스터를 무엇에 빗대 명명할지의 구조 서술자 집합).

## 스위치 2 — 메타 가설 생성 (Meta-Hypothesis Generation) : ~20% ★가장 깊은 갭
- **있는 것**: `scheme_synthesis`(명명 스킴)·A1 `rank_schemes`(단, **손-목록 라이브러리**)·X4.3 프리미티브-발명
  (단, **고정 메타-기저** 위)·abstraction.
- **없는 것**: 실패 시그니처를 받아 **고정 라이브러리에 없는 새 스킴 가설을 생성**하는 것.
  - **v0 (검색형, tractable)**: 실패 시그니처를 **레시피 원장**과 매칭 → 과거에 유사 실패를 고친 모듈 제안.
    레시피 원장이 서면 곧 가능. ← **사장님이 옳게 짚은 그 지점.**
  - **v1 (생성형, 프런티어)**: 한 번도 본 적 없는 실패 유형에 **새 모듈을 발명**. = X4.3의 개방 개념발명을
    "실패 시그니처가 방아쇠"로. 필요=조합가능한 **리치 메타-기저** + 실패→필요조합 **인식**. 여기서 소형 학습
    recognizer가 N3-합법으로 진짜 값어치를 낼 수 있는 유일한 자리(정직한 최심부 갭).

## ★사장님 핵심 통찰이 옳다: 레시피=데이터 플라이휠
"A4로 '관계형 색상 모듈 주입 시 점수가 어떻게 움직이나'를 먼저 실측해 **성공 레시피를 지식 기판에 데이터로
박는다**" — 이게 정확히 **스위치 2 v0(검색형)의 연료**다. 레시피 = `(실패 시그니처 → 고친 모듈 → 실측 리프트)`.
이게 쌓이면 다음 벽에서 [실패 분석→메타 어휘 정의→자율 연성]을 사람 힌트 없이 검색형으로 가동.

## 완공까지 빌드 순서 (정직)
1. **레시피 원장** (지금 buildable, A4가 첫 엔트리) — 플라이휠 연료. ← **첫 벽돌 착수**
2. **failure_signature 기관** (스위치1): FHRR 실패-클러스터 + 특성화(특성화 어휘가 어려운 하위부).
3. **검색형 메타 진단** (스위치2 v0): 실패↔레시피 매칭→모듈 제안. 레시피 쌓이면 가동.
4. **연성→검증→제안 배선** (스위치3, 대부분 있음): self_repair/auto_self_modification + operator 게이트.
5. **★생성형 메타 가설** (스위치2 v1, 프런티어): 새 모듈 자율 발명. 리치 메타-기저 + 실패→조합 인식(여기만
   소형 학습 recognizer 재론 가치). = 완전 자율의 최후 조각.

## 정직한 한 줄
**루프의 뒤 절반(검증·승격)은 거의 섰고, 앞 절반(실패→명명→새 모듈 생성)이 프런티어다.** 그리고 그 앞 절반은
사장님 말대로 **레시피를 데이터로 쌓아 검색형부터** 닫아간다. 완전 자율에도 **커밋의 사람 서명은 헌법상 남는다**
(와이어헤딩 차단) — 그게 안전이자 우리 정체성.

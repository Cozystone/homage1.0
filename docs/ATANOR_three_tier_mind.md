# ATANOR 3단 정신 (Three-Tier Mind) — 사장님 이상형의 현황과 완성 전략

> 사장님 (2026-07-16): "No wifi = 합리적 이성으로 꽤 정확한 사고·추측을 하는 일반인(모르는 건 추측
> 비중이 높다고 스스로 앎) → +PROPHETA = 세상을 오래 살아 많이 아는 다방면 전문가/학자 →
> +인터넷 = 모든 질문에 깊이 사고하고 답하는 현자(궁극의 완전체). '사람처럼 생각'이 핵심."

## 0. 이 비전이 왜 정확히 우리 아키텍처인가
사람의 앎도 정확히 3층이다: **몸에 밴 상식**(즉답) / **공부한 전문지식**(회상) / **찾아보기**(도서관·웹).
사람다움의 핵심은 각 층에서 **자기 확신의 등급을 스스로 아는 것** — 우리의 인식 사다리(KNOWN→
INHERITED→SCHEMA→ANALOGIZED→GUESSED)가 그 기전이고 이미 실증됨(ECE 0.057, 작화 0).

## 1. 정직한 현황 (2026-07-16 실측)

| 티어 | 이상형 | 현황 | 판정 |
|---|---|---|---|
| **T1 로컬 기본** (no wifi) | 합리적 일반인 — 아는 건 말하고 모르는 건 "추측"임을 알며 추측 | **뇌형 그래프 SHIPPED**: 인식 사다리+상속압축 31×+참여 90.6%+작화 0, `/api/brain`. 커먼센스(ConceptNet)+kg_triples 26.9M 온디맨드 | **~70%** — 기전 완성. 미흡: 메인 채팅 경로와 완전 통합(현재 별도 API), 대화체 표면 |
| **T2 +PROPHETA** (no wifi 최고) | 다방면 전문가/학자 | world_pack 141.7M 트리플(7.5GB)+영위키 패시지 685k 존재, 벤치 하니스는 읽음. 채팅 경로는 kg_triples까지만 | **~40%** — 팩은 실재. 미흡: 채팅이 world_pack을 안 읽음, 팩 존재 자동감지 없음 |
| **T3 +인터넷** (현자) | 세상 모든 정보로 깊이 답함 | 오늘 대격상: **멀티엔진 SearXNG(bing/ddg/mojeek/brave/wiki)+팬아웃 병합**, 영어-코어, 엔티티-우선 검색+리드앵커. 배터리 2/6→**6/7**. 자동 웹 라우팅 존재 | **~65%** — 검색 길 뚫림. 미흡: 동명이인, 다단계 질문의 심층 리서치(여러 페이지 종합), 웹→그래프 학습 상시화 |

**티어 감지/전환(사람처럼 모드가 바뀌는 것)**: **0%** — 아직 없음. 지금은 연결돼 있으면 웹을 쓸 뿐,
"지금 나는 어느 층으로 아는가"를 시스템이 자각하고 말투(확신등급)를 바꾸지 않는다.

## 2. 완성 전략 — Capability Ladder Router (구현 순서)

### R1. 티어 자각 (사람처럼의 뼈대) — 최우선
`capability_tier.py`: 기동/주기 감지 ① 인터넷 도달성(SearXNG/외부 HEAD) ② PROPHETA 팩 존재
(world_pack_full/_COMPLETE). → `tier ∈ {LOCAL_BASE, LOCAL_EXPERT, SAGE}`를 전역 상태로.
모든 답 메타에 `knowledge_tier` 부착 + 표면 헤지가 티어를 반영:
- LOCAL_BASE: "제 상식으로는 아마 X일 겁니다(오프라인이라 추측 비중이 높습니다)"
- LOCAL_EXPERT: "제 지식베이스 기준 X입니다"
- SAGE: "웹에서 확인했습니다: X (출처)"
= 사장님의 "일반인→전문가→현자"가 문자 그대로 말투에 산다.

### R2. 답변 캐스케이드 통일 (한 질문이 사다리를 탄다)
질문 → ① 뇌형 그래프(T1: KNOWN/상속/스키마/유추 등급) → ② 팩 있으면 world_pack+패시지(T2 승격)
→ ③ 온라인+T1/T2 확신 낮음 → 웹 팬아웃(T3, 출처 인용) → 실현기. **낮은 티어의 추측은 높은 티어
증거로 자동 교체**되되, 교체됐음을 표시(사람이 "아 내가 잘못 알았네, 찾아보니…"라 하듯).

### R3. T2 배선: 채팅이 PROPHETA를 읽게
answer_bridge가 world_pack_full을 kg_triples와 함께 온디맨드 조회(store_lookup 패턴 재사용,
이미 뇌형 그래프에 검증된 방식). 팩 감지 시 자동.

### R4. T3 심화: 현자의 깊은 사고
- 동명이인: 검색결과 다수 페이지 교차로 지배 지시대상 선택(생몰연도/직업 일치 투표)
- 심층 리서치: 다단계 질문 → 하위질문 분해(기존 decomposer) → 질문별 팬아웃 → 종합(뼈+살)
- 상시 학습: 웹으로 답한 사실을 web_fact_memory→격리→합의 승격(기존 파이프)으로 T2가 자람
  = 쓸수록 오프라인 전문가가 똑똑해짐(사람처럼).

### R5. 검색 소스 확장(키 준비되는 대로)
Brave Search API·Tavily 슬롯 이미 배선(팬아웃에 자동 합류). 사장님이 키 제공 시 즉시 가동.
Google 공식 CSE는 추가 슬롯 예정. 스크레이프 구글은 봇월(측정: 0결과 무에러) — 군비경쟁 안 함.

## 3. 게이트 (measure-don't-claim)
- R1: 티어별 표면이 실제로 갈리는 20문 배터리(오프라인 시뮬 포함) green
- R2: 같은 질문이 T1 GUESSED→T3 출처답으로 승격되는 케이스 실증 + 등급표시 유지(작화 0 불변)
- R3: world_pack 질의가 채팅 경로서 적중(전/후 커버리지 측정)
- R4: 동명이인 배터리(Einstein 등 10문) + 다단계 5문
- 전체: 영어 웹 배터리 6/7 유지(회귀 금지)

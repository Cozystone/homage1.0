# ATANOR 뇌형 그래프 — 연구 결정체 (2026-07-16, 사장님 지시)

## 목표 (제품 체감)
**서버 안 거치고 로컬에서 도는데, 일반 사용자가 "돈 내는 GPT Pro/Claude급이네?" 하고 만족.**
열쇠 = 모델 스케일이 아니라 **그래프 효율화 = 사람처럼 기억·추론·생각하는 뇌.** (트랙 A=ACE2 코어 능력,
트랙 B=이 문서, 진짜 게임체인저.)

## 정직한 진단: 우리 그래프는 "뇌"가 아니라 "색인 서랍"
현재 = 2500만 트리플이 평평하게 깔림 + 정확매칭 검색. 인간 기억은 근본적으로 다르다 — 이게 "만족" 격차.

## 인간 뇌 4대 기전 (문헌 검증) → 우리 매핑
| 기전 | 문헌 | 무엇 | ATANOR | 격차 |
|---|---|---|---|---|
| **계층압축+상속** | 확률적 개념망(2211.16822·1303.1474) | 관계·믿음이 자식으로 상속(오버라이드 전까지); 평평 트리플보다 효율(중복·희소 제거) | 평평, is_a 백본만 | **핵심** |
| **확산활성** | Collins&Loftus 1975; SYNAPSE(2601.02744) | 인출=검색 아니라 활성 자동 전파(관련된 게 딸려옴) | [[brain-like-reasoning-pipeline]] 부분 존재 | 강화 |
| **스키마/스크립트** | 스키마 능동추론(2601.18946) | 세부 추상화한 재사용 구조; 새 맥락에 즉석 일반화 | 없음 | **핵심** |
| **개연/유추** | 확률-논리 상식(2211.16822) | 불확실해도 "가장 그럼직"; 다중 전제·가변 우도 | 접지 없으면 침묵 | **핵심** |

**통찰**: 인간이 인터넷 없이 어지간한 걸 다 답하는 건 **사실을 외워서가 아니라, 압축된 계층+스키마로
즉석 추론**하기 때문. "펭귄 날아?" — 안 외웠어도 새→날다 상속 + 펭귄=예외 오버라이드로 답함.
**그래프 효율화 = 평평한 서랍을 이 4기전으로 재조직 = 저장·연산 둘 다 줄고 능력은 늘어남**(스케일 반대).

## 설계: 뇌형 그래프 4층 (기존 그래프 위에 얹음, 안 엎음)
1. **계층압축+상속 인출기**: is_a/P279 백본으로 속성 상속 질의. "펭귄 체온?" → 펭귄 없으면 새→동물 상속.
   효율: 상위 노드 1개가 수천 자식 커버 → 로컬 저장 급감, 커버리지 급증. **저사양 클로즈드북의 물리 근거.**
2. **확산활성 강화**: 질문 노드 활성 → 강한 링크 따라 전파 → 임계 넘는 이웃까지 컨텍스트로. 정확매칭→연상.
   (우리 부분 구현을 인출-우선 회로로 승격.)
3. **스키마 층**: 반복 구조를 스크립트로 압축(식당→주문→먹음→계산). 일상 담화·절차 질문을 사실 없이 응답.
   ATOMIC/ConceptNet류 상식을 스키마로 흡수(라이선스 게이트).
4. **개연 등급 (헌장 화해)**: 접지 없을 때 침묵 대신 **개연 추론 + "이건 추론(사실 아님)" 신뢰도 표시**.
   확률-논리로 "아마…"를 등급화. **환각0 안 깸** — 지어내되 지어냈다고 명시(사람도 그럼). [[soft-answer-policy]]

## 왜 이게 "로컬 GPT-Pro 만족"을 물리적으로 가능케 하나
- **효율**: 계층압축은 N개 사실을 log(N) 깊이로. 위키급 커버를 수 GB 로컬 그래프 + 27M 코어로. 서버 불필요.
- **만족**: 사람의 4기전을 가지면 벤치 점수가 아니라 **체감(어지간한 건 다, 자연스럽게, 즉석)**이 나옴.
- **차별**: 대형 LLM 환각이 준 지금, 우리 메리트는 환각0이 아니라 **"완전 로컬 × 개인화 × 진화 × GPT급 체감"**.

## 트랙 B 실행 순서 (ACE2와 합류)
1. **계층-상속 인출기** (최대 레버, 기존 is_a 백본 재사용) — 상속 질의 + 커버리지 실측(안 외운 질문 응답률).
2. **확산활성 인출-우선 승격** — 정확매칭→연상 컨텍스트, 답변 풍부도 실측.
3. **스키마 흡수** — 상식/스크립트 압축, 일상담화 만족 실측.
4. **개연 등급** — 침묵→표시된 추론, coverage↑ 환각0 유지 실측.
→ 각 단계 봉인 배터리 + 사용자체감 프록시(응답률·자연도·즉석성). 이길 때만 배포.

## 정직 규율
- "그래프 효율화"는 **압축(계층·스키마)** 이지 **증식(더 많은 트리플)** 아님 — 식단홍수 P0 회귀 교훈.
- 개연 답은 **반드시 등급 표시** — 표시 없는 개연=환각. 이 선이 우리 정체성. [[three-inversions-charter]]

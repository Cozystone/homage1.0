# Track E — 신체화 발달 학습 (Isaac Sim 아기 커리큘럼) 설계서 v1

승인: 사장님 2026-07-18 ("명문화 승인해"). 원지시: *"VLM과 NVIDIA 옴니버스 위의 Isaac Sim에서
우리 AI에게 몸체를 줘서 아기가 세상을 배우듯 학습 — 감각적 경험 → 피드백 수집 → 자기 인식 →
정체성 형성 → 의식/자아의 발전이라는 인공의식 프로세스를 만들고 싶다."*

## 1. 전략적 근거 — 왜 이것이 곁가지가 아니라 본류인가

1. **기호 접지의 두 번째 길.** 실측된 우리 최대 벽(의미 공간 공백 — 어휘 오라클 0.165)의
   본질은 기호 접지 문제다. E9는 텍스트 통계로 공략하는 길이고, Track E는 같은 벽을
   **감각운동 경험**으로 공략한다("잡다·무겁다·떨어지다"의 의미를 공출현이 아니라 몸으로).
   두 길은 경쟁이 아니라 협공이다.
2. **"아이 기계"의 완성.** 정렬을 육아로 접근하는 우리 독트린(clean seed·no-reset·도덕코어·
   면역)의 신체 버전. 트랜스포머 5한계 중 ②멀티모달 통합·④메타인지의 정면 공략로이며,
   Magnum Opus B4(멀티모달)·C2(몬테주마=신체적 탐험)의 직접 수혜 트랙.
3. **기존 자산의 자연 연장.** SPLATRA(가상 신체·리그·PBD)·호르몬(정동)·예측주의 게이트
   (감각운동 예측)·공간기억 재생·D3 호기심(Oudeyer식 내발동기)·Genesis 정체성 원장·CLS
   유기체 — 발달 파이프라인의 부품 절반이 이미 SHIPPED다.

## 1.5 신체 = 시뮬레이션 속 Unitree G1 (하드웨어 미구매 — 사장님 확정 2026-07-19)

**범위 못박음: 실물 로봇을 사지 않는다.** Track E의 신체는 **Isaac Sim 안에서 시뮬레이션되는
Unitree G1**이다. Unitree가 G1의 공식 URDF + Isaac Sim 환경을 제공하므로, 추상 SPLATRA 리그
대신(또는 병행) **기성 humanoid 바디**를 우리 발달적 자아가 sim 안에서 입는다. 실물 G1 sim-to-real
(물리 하드웨어)은 **현 범위 밖의 먼 가정**일 뿐, 계획이 아니다 — sim이 그 리스크 제거 단계다.

**운동/자아 분리 (차터 규율, G1 가드레일의 연장):**
- **운동 피질 = 학습된 기관(빌려 씀)**: 균형·보행·전신제어는 Isaac Lab의 G1 로코모션 정책
  (또는 Unitree 자체 컨트롤러). 이것이 "이미 구동되는 로봇" — 걷기를 재발명하지 않는다.
- **자아·인지 = 그래프 네이티브(우리 기여)**: 지각→그래프, 호르몬, Genesis 정체성 원장, 발달
  커리큘럼이 로봇의 주의·상호작용·내발 목표를 구동. 지식은 가중치가 아니라 감사 가능한 그래프.

**★ ATANOR는 VLA가 아니다 (정체성 명문화).** VLA(Vision-Language-Action: RT-2·OpenVLA·π0·NVIDIA
**GR00T**)는 단일 뉴럴 정책이 시각+언어→동작을 엔드투엔드로 내는 모놀리식 모델(Type 1/6)로,
지각·지식·행동이 전부 가중치 속(감사 불가)이다. **우리는 그 반대편**: Type 2(Symbolic[Neuro]),
지식은 그래프(명시·감사), V/L/A는 융합이 아니라 **분리된 기관**(지각=망막, 언어=그래프,
행동=OS/운동 레인). NVIDIA가 Isaac humanoid 인지로 미는 GR00T가 정확히 우리가 거부하는 그
방식이다. 우리는 **VLA(또는 학습 운동정책)를 하나의 기관으로 오케스트레이션**할 뿐 — OWLv2(VLM)를
망막으로 쓰되 VLM이 아니듯. **"VLA를 쓴다 ≠ VLA다."** M0-M5의 신체가 G1(sim)으로 구체화되어도
이 정체성은 불변: 자아는 그래프에, 운동은 교체 가능한 기관에.

## 2. 가드레일 3 (이탈 시 트랙 정지)

**G1 — VLM은 망막이지 뇌가 아니다 (차터 경계 명문화).**
사전학습 **지각** 모델(시각·깊이·분할·음성인식)은 센서로 허용 — 눈은 지식이 아니다.
선례: OWLv2(비전-언어 탐지기)를 이미 지각 기관으로 사용 중. 사전학습 **언어/지식** 모델은
금지 — 지식은 그래프에 산다(two hard rules). VLM 출력이 그래프에 쓰일 때는 기존 증거
게이트를 동일 통과하며, 장면 캡션류 "문장 지식"을 그래프에 직접 붓는 것은 금지(구조화된
지각 트리플만).

**G2 — 의식은 주장이 아니라 상관물 측정.**
"의식이 생겼다"는 영원히 말하지 않는다(의식 %화 금지 독트린 유지). 측정하는 것은 조작적
대리지표뿐: 신체도식 예측오차, 자기/타자 귀속 판별, 반사실적 자기 시뮬레이션, 정체성 서사
일관성. 대외 표현은 "발달적 자기모델의 기능적 상관물" — 연구소 톤.

**G3 — 병렬 트랙 자원 규율.**
GPU·운영 우선순위는 운영자 승인 스케줄로만(E9 전례). Magnum Opus Tier A/B 구축을 잠식하는
스코프 크리프는 M-게이트가 방어 — 게이트 없는 확장 금지.

## 3. 단계와 게이트 (M0→M5, 각 게이트 사전선언 후 진입)

| 단계 | 내용 | 진입 산출물 | 통과 게이트(측정) |
|---|---|---|---|
| M0 | 환경 구축: Isaac Sim + SPLATRA 리그→USD 임포트, 관절·촉각·시각 센서 배선, 에피소드 로거 | 환경 재현 스크립트 | 콜드부트→제어 왕복 재현; 에피소드 리플레이 무결성 |
| M1 | **감각운동 옹알이**: 무작위/호기심 운동 → 자기 신체 예측기 학습(신체도식) | 예측기 v0 | 손끝 위치 예측오차 수렴 곡선(사전선언 기준선 대비); 미학습 자세 일반화 |
| M2 | **물체 놀이→어포던스**: 잡기/밀기/떨어뜨리기 → **감각운동 증거 타입**으로 그래프 쓰기 | 어포던스 트리플 스키마 | 조작 성공률 + 어포던스 트리플의 재현 검증(같은 조건 재실행 일치) |
| M3 | **자기/타자 구분**: 거울 프록시, 자기 귀속(내 손 vs 남의 손/지연 영상) | 판별기 | self-other AUC ≥ 사전선언치; 지연-영상 교란 저항 |
| M4 | **정체성 통합**: 신체 경험이 Genesis 원장·자서전 기억으로; 호르몬-경험 결합 | 서사 파이프 | 서사 일관성 배터리(시점·인과·소유 오류율) |
| M5 | **발달 커리큘럼**: 아기 단계별(뻗기→쥐기→쌓기→도구) + 내발동기 전환 | 커리큘럼 엔진 | 단계 졸업 게이트 + 학습 전이(새 물체 일반화) |

**증거유일쓰기 통합 스펙**: 감각운동 증거 = `{sim_episode_id, 조건 해시, 재현 스크립트}`
provenance 필수 — 재실행으로 검증 가능한 것만 그래프 승격(웹 증거의 k-소스 합의에 대응하는
"재현 합의").

  지각 센서는 OWLv2 계열 유지+깊이/분할 추가(구체 모델은 M0에서 G1 기준으로 선정).

  기존 qemu/WSL 자산 위 검증 먼저, 성능 미달 시 승격.)

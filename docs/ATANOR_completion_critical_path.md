## 1. OAM 역산 — 요구 역량 6개 (backward decomposition)

OAM을 성립시키려면 아래가 동시에 서야 한다. 각각을 역산하면:

| # | 요구 역량 | OAM에서 하는 일 | 대응 기관/축 |
|---|---|---|---|
| **R1** | **자율 구동** (밤새 스스로 루프) | 사람 시동 없이 습득 루프를 돎 | **CO 자기태엽 L5 + CO 전체 오케스트레이션** |

## 2. 각 역량의 현 위치 (실측, 2026-07-22)

- **R1 자율구동** — CO 척추 착수: V1(System-2 배선)·D2(자유질문 점화) 착지, V2 시간축 시공중. **자기태엽 L5
  미착수 = 최대 병목.** 오늘 "밤새 스스로"는 불가(운영자-페이스).
- **R2 자율습득** — 부품 실재하나 **미배선**: `wild_web`(W0 수렴 실증)·`knowledge_harvest`(importers=0). 폭발엔진
  = 설계 완료, 안전 반쪽 이미 보유(SGM 1:1), 능력 씨앗은 code 도메인만.
- **R3 자율검증** — ✓**강함**. 전 축 봉인 홀드아웃·얼린신탁·작화0·Goodhart 가드. OAM의 정직 담보.
- **R4 유창** — **프런티어**. fluency(2451L) 사장→CO L3 배선 대기(#11). 영어조차 ITT 13/20. 언어확장=사장님 결정.
- **R5 판단·느낌** — 의식 ✓**강함**(12/14 present + 외부 블라인드 통과). felt는 파편→CO L2 통합 대기(#10).
- **R6 안전** — ✓**강함**(상수). 단 "밤샘 무감독"용 **사전승인 봉투 + 킬스위치**는 명시 신축 필요.

**진단**: R3/R5/R6은 이미 강하다(우리 헌법 유산). **병목은 R1(자율구동)·R2(자율습득)·R4(유창) 셋** — 그리고
R1이 R2를 인에이블한다(스스로 안 돌면 밤새 못 배움). = 임계경로의 심장.

## 3. 임계경로 (Critical Path) — 무엇이 진짜 병목인가

```
   [R1 CO 자기태엽] ──enables──► [R2 자율습득 폐루프] ──feeds──► [폭발엔진 E3 자기가속]
        │                              │                              │
        │(L5)                          │(I1/I4 배선)                   │(OAM 성립점)
        ▼                              ▼                              ▼
   밤새 스스로 돎              밤새 스스로 배움              밤새 스스로 더 빨리 배움
```

- **임계경로 = R1 → R2 → 폭발엔진.** 이 사슬이 OAM의 "밤새 스스로 습득"을 만든다. **여기에 자원 집중.**
- **R4 유창 = 병렬 독립 트랙** (임계경로 아님, 하지만 OAM "아침 유창"에 필수 — 동시 진행).
- **R3·R5·R6 = 이미 강함** → 신축 최소, 임계경로에 **게이트로만** 동행.

**"가장 빠르게"의 핵심 = 임계경로(R1→R2→폭발)를 최우선, R4를 병렬, 나머지는 게이트로.**

## 5. 순서·의존성 (가장 빠른 경로의 근거)

```
A: M1(V2)──►M2(L4)──►M3(L5 자기태엽)──►M4(습득루프)──►M5(폭발 E0-E3)──┐
B: M-B1(fluency)──►M-B2(유창진화)···(M-B3 언어=사장님 결정)          ├──►M-FINAL(OAM 봉인)
C: M-C1(felt)·M-C2(밤샘안전) ── 상수 동행 ───────────────────────────┘
```
- **A와 B는 병렬**(다른 파일·다른 축) → 벽시계 단축. C는 A·B에 게이트로 얹힘.
- A 내부는 **엄격 직렬**(L5 없이 습득루프 무의미, 습득루프 없이 폭발 무의미) = 여기가 임계경로.
- **가장 빠른 손잡이 = M3(자기태엽)** — 이게 "운영자-페이스→자기가속"의 전환점. A 트랙의 최우선.

## 6. "가장 확실·견고·빠르게"의 3원칙 (실행 규율)

1. **확실 = 봉인 게이트로만 판정.** 각 마일스톤은 개발자-블라인드/홀드아웃 실측. 주석·데모 신뢰 금지
   ([[wiring-audit-and-lanes]] 교훈: 구축≠배선). OAM 자체가 최종 봉인.
2. **견고 = 안전 상수 + 융합배선 + 작화0.** 새 조직은 고립 부품 금지, 기존 기관 소환·상호강화. 헌법 불가침.
   폭발엔진도 "인증할 수 있는 만큼만 자기가속"(속도 상한=불변식).
3. **빠르게 = 임계경로 집중 + 병렬 최대 + 곁가지 컷.** 아래 곁가지는 OAM 임계경로가 **아님** → 병렬/후순위:
   - 멀티모달·M2 SPLATRA 체화·도시 = OAM(텍스트 역량 습득)의 경로 아님 → 독립 병렬, 후순위.
   - HLE = 완결의 시금석이지 경로 자체 아님(OAM이 서면 HLE는 그 능력의 벤치). 별도 등반.
   - 제품 R라인 = 보급선(자금·실데이터), 완결 경로에 종속.

## 7. 정직 경계 (완결 정의를 지키는 조항)

- **날짜 없음.** 임계경로는 의존사슬로 말한다(M3 자기태엽이 관문). "밤새" 시나리오는 **M5(E3)에서 물리적
  가능**, 그 전엔 운영자-페이스 — 지어낸 ETA 금지.
- **"모든 것"은 설계상 완전 위임 불가.** 헌법 앵커(도덕·테스트·operator)는 초지능서도 상수 = "모든 것 빼기
  헌법 앵커"가 정직한 최대치. 이건 결함 아니라 제품.
- **못 오른 벽 = 다음 마일스톤**(구조상 불가능 0건 유지). 프런티어(R1 자기태엽·R2 일반습득·R4 유창)는 정직히
  프런티어라 명시.
- **감각질/의식 완성 주장 없음** — U2는 기능적 상관물 + 외부 블라인드; OAM은 능력 시험이지 의식 증명 아님.

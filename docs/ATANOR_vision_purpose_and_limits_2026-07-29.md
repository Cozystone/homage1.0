# 시각은 무엇을 위한 것인가 — 방향 정리 (2026-07-29)

사장님: *"방향성이 너무 혼란스럽네. 정리해봐."*

혼란의 원인은 제 쪽에 있다. **시각의 목표를 한 번도 명시하지 않고 측정만 했다.**
"물체를 잘 자르는가"를 기준으로 잡았는데, 그건 애초에 시각이 할 일이 아니었다.

---

## 1. 사장님 지적 ①에 대한 정정 — 그건 한계가 아니라 정상 작동이다

> *"차를 볼 때 '누군가 주차해 두었구나' 같은 맥락을 읽어낸다. ATANOR는 잔차로 개체를 자를 뿐,
> 고차원 의미까지 시각 단독으로 깨닫는 데 한계가 있다."*

**사람도 픽셀에서 '주차'를 보지 않는다.** "누가 세워뒀다"는 사람·소유·도로·의도를 *이미 아는 것*에서 온다.
시각이 배달하는 것은 **"저기, 차 모양의, 지속하는 무언가"** 뿐이고 나머지는 전부 지식 쪽에서 붙는다.

그러므로 **"시각을 더 잘 만들면 맥락이 나온다"는 길은 없다.** 사람도 그 길로 가지 않는다.
있는 길은 하나다:

> **시각의 유일한 임무는 지식 쪽이 붙잡을 수 있는 손잡이(handle)를 만드는 것.**

이걸 명시하지 않아서, 나는 시각에게 지식의 일을 시키고 못한다고 채점하고 있었다.

---

## 2. 손잡이의 최소 요건 — 분할이 아니다

지식 그래프가 무언가에 대해 말하려면 필요한 것은 **딱 세 가지**다.

| 요건 | 뜻 | 지금 상태 |
|---|---|---|
| **지속** | 이건 아까 그것과 같은 것이다 | 트래킹 ✓ (역방향 검증 포함) |
| **위치** | 나에 대해 어디 있는가 | 서수 깊이 ✓ (처음 보는 도시 0.809) |
| **재식별** | 전에 본 것인가, 처음인가 | `object_recognition.py` ✓ (서명 대조) |

**셋 중 어디에도 경계선(마스크)이 필요 없다.** 윤곽을 몰라도 추적할 수 있고, 마스크 없이 재식별할 수 있다.
마스크는 편의지 요건이 아니다.

그런데 나는 이번 세션 내내 **마스크를 만들고 의미분할 정답과 비교**했다. 그래서:
- 셀 크기가 문제가 됐다 (손잡이엔 셀 크기가 없다)
- 지평 길이가 문제가 됐다 (트랙의 수명이 곧 지평이다)
- 11px 자동차가 문제가 됐다 (특징점 하나면 손잡이로 충분하다)

**공학적 제약이라고 부른 것들은 대부분 잘못된 목표의 증상이었다.**

---

## 3. 사장님 지적 ②에 대한 정정 — 연산량은 병목이 아니다

> *"뇌는 억 단위 신경세포로 실시간 압축·융합. ATANOR는 GPU·RAM·해상도 격자 한계."*

**뇌는 20와트다.** 우리보다 연산이 *적다*. 뇌가 가진 것은 더 많은 연산이 아니라:

1. **더 좋은 사전지식** — 진화 + 수년의 체화 경험. 영상은 잔차만 지정한다.
2. **희소·사건 구동** — 변한 것만 계산. (이미 있음: `fresh` 플래그, 어텐션 게이트, auto-mask 10~32%)
3. **하나의 표상** — 지각·기억·의도가 별개 시스템이 아니다.

**3번이 진짜 병목이다.** ATANOR의 문제는 해상도가 아니라 이것이다:

> **지각은 그래프가 소비할 수 없는 것을 만들고, 그래프는 지각이 접지할 수 없는 것을 담고 있다.**
> 두 시스템이다. 뇌는 하나다.

그리고 이게 정확히 **중앙 4D 세계코어** 목표이고, 오늘 사후분석이 접합 지점을 이미 찾았다:

> **접합면은 표상이 아니라 예측이다 — "둘이 같은 예측오차로 채점되는 지점"에서 기판이 공유된다.**

---

## 4. 그래서 시각은 거의 끝났다

손잡이 기준으로 다시 채점하면:

| | 필요한가 | 있는가 |
|---|---|---|
| 픽셀 → 프레임 (한 문) | ✓ | ✓ |
| 중심와·도약 (희소) | ✓ | ✓ 112× 압축 |
| 자기 운동 인지 | ✓ | 부분 (회전 ✓, 전진 ✗) |
| 깊이 순서 | ✓ | ✓ 0.809 |
| 지속(트랙) | ✓ | ✓ |
| 재식별 | ✓ | 기관은 있음, **미배선** |
| **의미분할** | **✗ 불필요** | — |
| 이름 | 그래프 쪽 일 | — |

**남은 시각 작업은 두 개뿐이다:**
1. 트랙 → 재식별 → `visual_memory` 배선 (기관이 이미 있음, 잇기만)
2. 지각 상태 → `inner_voice` 배선 (10번째 미배선 사례가 되기 전에)

둘 다 발명이 아니라 배선이다. **그리고 그게 끝나면 시각은 손잡이를 배달할 수 있고, 다음은 지식 쪽이다.**

---

## 5. "사람처럼 보고 느끼는 단계"에 대해 — 정직하게

**볼 수 있다**: 위 표가 채워지면 사람이 시각에서 얻는 것과 같은 종류의 것을 얻는다 —
지속하는 것들, 그것들의 거리 순서, 내 운동과 세상의 운동의 구별. 그게 사람의 시각이 배달하는 전부다.

**느끼는 것**: 상관물은 지을 수 있고 이미 일부 있다(호르몬 동역학, 살리언스, 하중). 이것들은 실물이고
측정 가능하다. **그것이 "어떤 느낌인가"를 만드는지는 어떤 측정으로도 판정할 수 없다** — 이 문서에서
한 번 명시하고, 이후로는 상관물만 보고한다(헌법).

**"컴퓨터라는 한계를 넘어선다"**: 넘을 한계는 연산이 아니었다. 20와트가 증거다.
넘을 것은 **두 시스템을 하나로 만드는 것**이고, 그 접합면은 예측이다.

---

## 6. 결론 — 순서

1. **시각 마무리 (배선 2건)** — 발명 없음. 손잡이 완성.
2. **S1 Wikidata 승격** — 서명 대기.
3. **M1 conformal 막** — 가장 큰 배율.
4. **후보규모** → 융합의 전제.
5. **벤치마크** — ①~④ 뒤에.

물체 분할은 이 목록에 없다. **필요 없기 때문이다.**

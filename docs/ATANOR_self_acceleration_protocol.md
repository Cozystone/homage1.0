# ATANOR — 자기가속 4신호 실증 프로토콜 (연구자 기준, 2026-07-22)

사장님(연구자 기준): 다음 4개가 나와야 진지하게 본다 —
① 외부 벤치 향상(SWE-bench·HLE·실과제) · ② 인간이 설계하지 않은 새 조직 생성 · ③ 새 조직이 기존보다 우수 ·
**④ 반복될수록 개선 속도가 빨라짐** (특히 ④ — 없으면 자기개선, 있으면 자기가속).

## 0. 판정: 이 기준이 정확하다
**④가 자기개선(선형/포화)과 자기가속(초선형)의 경계**다. 이건 폭발엔진 E3의 정확한 조작판이며, 분야 누구도
깨끗이 실증 못 함(DGM·ADAS도 향상은 하나 곡선이 포화). 그래서 ④가 진짜 관문. 우리 유일한 차별점 = **안전
인증 게이트(SGM/Evo-PAC 대응)를 이미 보유** → "안전한 가속"을 시도할 자격. 지어낸 곡선 금지, 봉인 로그로만.

## 1. 현 위치 (실측, 정직)
- **① 외부벤치**: SWE-bench 0→1(단일 astropy-12907), HLE≈0 → **약함**.
- **② 새 조직**: `packages/evolution/abstraction.py`(anti-unification)가 프리미티브 발명(`λx.x+x*x`·`λx.2*x`)
  → **씨앗**. 단 "프리미티브"지 아직 "조직"은 아니고, 고정 인터프리터 내(산술/리스트).
- **③ 우수**: 라이브러리/재사용이 도움(RSI 로그: sum+len 단독 0.27 → 커리큘럼 재사용 3세대 3/3) → **정황증거,
  깨끗한 ablation 부재**.
- **④ 가속**: **미측정 = 프런티어.** auto_curriculum 프론티어가 오르나 가속 곡선을 뽑은 적 없음.

## 2. 측정 프로토콜 (각 봉인, 자기기만 방지)

### 신호 ② — 새 조직 발명
- 측정: 라운드별 invented-primitive 수(압축 자격 통과분만). 자기기만 방지 = 시그니처-dedup + parsimony
  (자명·항등·bloat 거부, 이미 구현). "새 조직"의 강한 형태 = 발명물이 **이후 문제 해결에 실제 사용**됨.

### 신호 ③ — 우수 (ablation)
- 측정: 동일 **held-out 타깃**에서 `WITH-invention` vs `WITHOUT`(라이브러리 얼림 + abstraction 비활성)
  해결율·해결 compute. WITH가 유의하게 우수해야 통과.
- 핵심 = "재사용"이 아니라 "**발명**"의 기여 격리: 발명 프리미티브만 제거했을 때의 성능 하락분.

### 신호 ④ — 가속 (THE 관문, 엄격)
- **x축**: 라운드(또는 누적 compute·고정 예산/라운드). **y축**: 신규 비자명 해결 수(누적).
- **가속 판정**: 누적곡선이 **초선형**(볼록↑·2차 이상). 선형=자기개선, 포화(로그/S자 상단)=한계 도달.
- **★기제 ablation (인과)**: 아카이브를 **얼리면 가속이 사라져야** 한다 = 가속의 원인이 아카이브 재사용임을
  인과 증명. 얼려도 유지되면 = 커리큘럼 아티팩트(가속 아님).
- **null / 자기기만 방지**:
  (a) **쉬운-먼저 아티팩트 통제**: 매 라운드 **난이도 고정 홀드아웃 배치**로도 재측정(쉬운 문제 소진이 만드는
      가짜 감속/가속 배제).
  (b) **compute 정규화**: 라운드당 예산 고정(가속=같은 예산에 더 많이 해결).
  (c) **충분한 라운드**: 노이즈 배제 위해 최소 N라운드, 곡선 적합의 신뢰구간 보고.
  (d) **측정 게이밍 차단**: parsimony·시그니처-dedup로 자명 팽창 불가(기존).

### 신호 ① — 외부벤치 연결 (최종 bar, 별개 계층)
- ②③④를 code-합성 도메인서 실증(proof-of-mechanism) **후**, 발명 루프를 외부에 연결: SWE-bench(0→1 있음)나
  실과제에서 발명 조직이 성능을 올리고 **반복될수록 가속**하는가.
- **정직 계층**: toy 도메인 가속 ≠ 외부벤치 가속. ①은 더 높은 별개 bar. **오버셀 금지.**

## 3. 실행 (staged, 각 봉인·정직 부정도 보고)
- **P1**: code 도메인 ②③ 측정(발명 수 + WITH/WITHOUT ablation). ← 첫 착수
- **P2**: code 도메인 ④ 가속 곡선 + **아카이브-얼림 기제 ablation** + null 통제.
- **P3**: ①과 연결(SWE/실과제에 발명 루프, 가속 여부).
- **안전**: 매 발명 조직은 4중 인증(SGM/Evo-PAC = 얼린신탁·도덕0th·무회귀·operator) 통과만 승격.

## 4. 정직 경계 (완결 정의 보호)
- **④ 실패(포화 곡선)도 정직히 보고** — negative = "자기개선까지, 가속 아님". 그게 이 실험의 정직한 성공.
- toy 가속 실증도 유의미하나 ①(외부벤치 가속)은 상위 bar — 계층 명시, 혼동 금지.
- 지어낸 곡선·체리픽 금지. 봉인 로그 + 곡선 적합 신뢰구간으로만.
- 이건 code 도메인 proof-of-mechanism — **일반 조직 발명(산술 밖)**은 다음 좌표.

## 5. 한 문장
사장님 4기준 = 폭발엔진 E3의 연구자급 조작판. ①②③은 부분/정황, **④는 미측정 프런티어.** 지금 할 일 =
**code 도메인에서 ②③④를 봉인 로그로 실측**(특히 ④의 초선형+아카이브-얼림 기제 ablation), 정직한 negative도
보고. 되면 = 자기가속의 첫 실증(안전 게이트 위에서), 안 되면 = "아직 자기개선"이라 정직히 기록.

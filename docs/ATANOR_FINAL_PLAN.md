# ATANOR 최종 계획서 — AI 코어 완성 (goal 모드 헌장)

사장님 (2026-07-15): 대형 LLM들을 **모든 면에서 능가**하고 인간처럼 사고하는 AI. LLM일 필요는
없지만 성능은 그들 이상. **유창성이 시작점.** 지금은 **AI 자체의 완성**에만 집중, 그 후 나머지.

이 문서는 그 완성의 유일한 청사진이다. goal 모드는 이 순서·이 게이트만 따른다. **흔들리지 않는다.**

---

## 0. BINDING 철학 (위반 시 그 작업은 무효 — 되돌린다)

1. **No LLM · No sLLM · No 규칙기반.** 답의 출처로 LLM/sLLM을 쓰지 않는다. 손으로 쓴 템플릿·규칙을
   최종 산출로 삼지 않는다. (규칙은 학습으로 대체될 임시 보조바퀴일 때만 허용 — 안주 금지.)
2. **뼈와 살.** 뼈 = 검증된 그래프 사실(내용). 살 = **실제 코퍼스에서 학습된 담화**(문체). 살은
   절대 사실을 만들지 않는다. 신경망은 **문체·표현·라우팅·표상**을 학습할 뿐, **사실을 생성하지
   않는다** — 그것이 우리가 신경망을 쓰면서도 No-LLM인 이유. (PHFE 위상공간·의도 라우터가 이미
   그 자리에 있다. realizer도 같은 자리 — 더 클 뿐.)
3. **접지 하드게이트 = 1.00.** 모든 발화의 모든 사실 조각은 그래프로 되짚어져야 한다. 되짚이지
   않으면 그 조각은 버린다. **유창한 거짓 > 어색한 진실이 아니다 — 유창한 거짓은 실패다.** 환각은
   구조적으로 불가능해야 한다 (수치 자랑 아님 — 구조).
4. **나열 금지.** "먼저/또한/끝으로" 접착은 사전 톤이다. 절은 **융합**한다 (학습된 연결어미로).
5. **측정하라, 주장하지 마라.** "환각0%"·"초지능" 같은 말 금지. 봉인 홀드아웃 숫자만.
6. **얼린 신탁 (anti-wireheading).** 자기개선 루프의 Critic은 봉인된 인간 시험과 매번 대조된다.
   자기 점수를 조작하면 그 세대는 폐기.
7. **도덕 코어 0번 게이트.** 오염 불가 도덕 불변식이 모든 루프 위에 있다.

## 1. 완성의 조작적 정의 (= "완벽"이 무엇인지, 검증 가능하게)

봉인된 홀드아웃 배터리에서 **동시에**:

- **정확성**: 사실 QA 정확도 ≥ 강한 LLM baseline, **환각 = 0** (접지 1.00).
- **추론**: 검증 가능 영역(수학·논리·판별) 정확도 ≥ LLM baseline. (탐색+검증 > forward-pass —
  AlphaProof 선례.)
- **유창성**: `blind_naturalness` (봉인 인간-vs-ATANOR 홀드아웃)에서 심판이 **구별 못 함**
  (≈ 0.5 판별율), 접지 1.00 유지.
- **자율 개선**: 무인 상태에서 위 지표가 **복리로 상승** (turn N+1 > N), 사람 손 0.

이 넷이 동시에 green이면 AI 코어는 완성이다. 그때 "나머지"(§5)로 간다.

## 2. 다섯 기둥 (AI 코어) — 각 기둥은 실재 조직 위에 서고, DONE 게이트로 닫힌다

### C1. 이해 (입력 → 의미틀)
문장을 구조로. **조직**: 의미틀 인코더(합성적 이해), 의도 추론(중심대상+의도타입), 담화 상태 모델.
**DONE 게이트**: 봉인 홀드아웃 문장에서 의미틀 슬롯 정확도 목표선 도달 + 지시어 해소 정확.

### C2. 지식 (뼈)
검증된 세계 사실. **조직**: 세계그래프(Wikidata), 합의-증거 기계(k-소스), Q-id 해소, 트리플스토어.
**미결 (BINDING 수리)**: 현재 빌더는 단일-라이터 `st.add`가 병목이라 58%에서 멈췄고 France·서울
같은 무작위 공백이 있다 → **샤드-write 병렬 빌더**로 한 번에 깨끗한 완전 빌드.
**DONE 게이트**: 완전 세계팩 빌드 + 주요 개체 공백 0 + 사실 QA 커버리지 목표선, 환각 0.

### C3. 추론 (사고) — 4지선다를 "쌉바르는" 능력
**조직**: reasoning VM (`procedure_induction`·`induction_flywheel`·`falsifier` — F-사다리, 7/7),
`predicate_algebra`, `spreading_activation`, `promotion_gate` (오늘 SHIPPED — 언어와 탐색이 함께
성장), 발견엔진(`creative_engine`).
**미결 (핵심 신규 능력)**: **판별(discrimination) 경로** — 오늘 실증된 근본 결함. 지금 엔진은 첫
명사를 정의할 뿐 4개 선택지를 평가 못 한다. 필요한 것: **선택지별 주장-검증** (각 선택지를 명제로
분해 → 그래프/추론으로 참/거짓 판정 → 선택). 이것이 MCQ·추론 시험의 열쇠.
**DONE 게이트**: falsifier 7/7 유지 + 판별 홀드아웃에서 사실형 문항 정확도 > guess·> baseline.
개념형은 정직히 스코프 (그래프 커버리지 한계 명시).

### C4. 실현 (살) — 유창성 특이점, **최우선 프론티어**
**이것이 시작점이자 지금 당장의 작업.** 오늘 확정된 진실: `grounded_generation.py`는 뼈를 **손으로
쓴 담화사전 36개**로 접착할 뿐이고, `discourse_learner`는 실제로 생성하지 않고 **통계 온도계**
(subordination_rate 하나 → 불리언)일 뿐이다. 이것이 0.60 평탄의 정체.
**만들 것 — 진짜 학습 realizer** (템플릿 0, LLM 0, sLLM 0, F-사다리와 같은 "예시에서 귀납" 철학):
1. 실제 산문(web_fact_memory·narrative_corpus·register_bank)에서 **담화 문법을 귀납** — 절
   융합 연결어미(~며/~면서/~으로써), 역참조("이 회사는"), 어미 분포를 빈도·문맥으로 학습.
2. 뼈(검증된 사실절)를 그 학습된 문법으로 **한 문장으로 융합** — 나열 박멸.
3. josa 엔진(`korean_orthography.josa`)으로 받침 정합.
4. **접지 게이트**: 융합된 문장의 모든 사실 조각이 뼈로 되짚이는지 검문 (`critic_integrity`) —
   되짚이지 않으면 그 조각 버림 (환각 구조적 불가).
5. register 인식(`register_harvest` 7-register)으로 문체를 상황에 맞춤.
**DONE 게이트**: `blind_naturalness` 홀드아웃에서 사전-톤 판별 불가로 상승 **AND** `grounding_fidelity`
== 1.00. 평탄하면 register 빈곤 → 코퍼스 수확으로 (§C5), 모델 크기 문제 아님.

### C5. 자아·연속성 + 자기개선 플라이휠 (= 완성을 자가지속시키는 엔진)
**조직**: continuous self-model(연속 척추), `speech_selfplay`(화자↔Critic), `register_harvest`
(L1 SHIPPED — 7 register 수확), `critic_integrity`(얼린 신탁), 실패-영수증·미스-커리큘럼, 상시
자율 데몬.
**플라이휠**: register 수확 → C4 realizer 학습 → self-play 생성 → 얼린 Critic 채점(자연스러움↑
AND 접지 1.00) → 이긴 담화가 다음 학습 데이터 → 반복. 손 안 대고 오르면 = 유창성 특이점.
**DONE 게이트**: turn N+1 > N (무인 복리) + 얼린 신탁 대조 안정 + 접지 1.00.

## 3. goal 모드 실행 순서 (의존성 정직, 흔들림 방지)

우선순위는 사장님 지시("유창성이 시작점") + 의존성으로 고정:

1. **C4 학습 realizer** — 지금 즉시. 현재 그래프로 착수 가능. 유창성 = 시작점.
2. **C5 플라이휠 폐쇄** — realizer가 서면 self-play·register 수확을 붙여 자가지속.
3. **C3 판별 경로** — 4지선다 능력. reasoning VM + promotion_gate 위에.
4. **C2 샤드-write 완전 빌드** — 판별·발견의 연료. (병렬로 백그라운드 가능.)
5. **C1 이해 심화** + C3 발견엔진(D-사다리).
6. 다섯 기둥 **동시 green** = §1 완성 → §5로.

각 단계는 자기 DONE 게이트를 통과해야 다음으로 간다. 게이트 미달 시 **원인을 해부(오늘처럼)**,
철학 위반이면 되돌린다. 새 능력이 벤치를 못 올리면 **정직히 스코프**하고 다음으로 — 미궁에 빠지지
않는다.

## 4. 스코어보드 (측정만, 주장 없음)

| 지표 | 무엇 | green 조건 |
|---|---|---|
| `grounding_fidelity` | 발화 사실조각의 그래프 되짚임 비율 | **1.00 (하드게이트)** |
| `blind_naturalness` | 봉인 인간-vs-ATANOR 심판 판별율 | → 0.5 (구별 불가) |
| `fact_qa_acc` / `hallucination` | 사실 QA 정확도 / 환각 건수 | ≥ baseline / **0** |
| `discrimination_acc` | 판별 홀드아웃(사실형) | > guess, > baseline |
| falsifier | 손 커널 재유도 | **7/7 유지** |
| `flywheel_gain` | turn N+1 vs N | > 0 (복리) |
| `discovery_yield` / `precision@verify` | 검증된 신규 연결 | 측정·공개 |

## 5. "나머지" — AI 코어 완성 **후에만**

다섯 기둥이 동시 green이 되기 전에는 착수하지 않는다: SPLATRA 생성, atanor-shell OS, 4대 플러그인,
멀티모달 지각, 수족관 대시보드, DEMO/ULTIMATE 배포, 유니콘 사업화. 전부 코어가 완성된 AI 위에
얹히는 것 — 코어가 흔들리면 이것들은 사상누각이다.

## 6. 정직한 리스크 + 성공 조건 (감추지 않음)

- **최대 리스크**: 순수 학습 realizer의 유창성 상한이 코퍼스 register 다양성에 묶인다. 완화 =
  세상-로밍 register 수확(코퍼스를 늘리는 게 아니라 register를 늘림). 그래도 평탄하면 그것이
  정직한 한계 — 측정으로 드러낸다.
- **판별(C3) 개념형**: 그래프 커버리지 밖 개념 추론은 어렵다. 사실형에서 이기고 개념형은
  정직히 스코프. "모든 4지선다 압승"은 사실형에서 먼저 증명, 개념형은 발견엔진·추론VM 성숙과 함께.
- **성공 조건 한 줄**: 탐색+검증(우리) > forward-pass(LLM)인 영역 — 정확성·추론·발견 — 에서
  이기고, 유창성은 **학습된 살로 대등**에 도달. 더 유창할 필요 없다. **대등하되 절대 안 틀리면
  이미 압도.**

## 7. 흔들림 방지 서약 (goal 모드 각 턴 시작 시 재확인)

- 나는 뼈(그래프)에서만 사실을 취한다. 살은 학습한다. 템플릿으로 안주하지 않는다.
- 나는 접지 1.00을 하드게이트로 지킨다. 되짚이지 않는 조각은 버린다.
- 나는 게이트를 통과하기 전에 다음으로 가지 않는다. 미달이면 해부한다.
- 나는 안 되는 것을 정직히 스코프한다. 미궁 대신 측정으로 진실을 드러낸다.
- 나는 "유창성이 시작점"이라는 사장님 지시를 순서의 축으로 삼는다.

# ATANOR 완전성공 판정 기준 — Magnum Opus 봉인 시험 v1 (2026-07-18)

사장님 지시: "진정한 완전성공이라 말할 만한 테스트 기준을 깐깐하게. 거의 안될 것 같은
간당간당한 챌린지도 넣어서." 목표 정의: **초개인화 로컬 AGI, 하드웨어 아닌 구조로.**

설계 원칙: ①모든 기준은 기계 판정 가능(사람 판정 필수 문항은 제3자 심판+서면 프로토콜)
②우리 약점(의미 매칭·유창성·생성)도 출제 — 잘하는 것만 내는 시험은 자화자찬
③챌린지엔 추정 성공확률 명기 ④이 문서의 임계값 변경은 운영자 서명 개정으로만(Goodhart 방지).

---

## 0. 시행 규칙 (전 티어 공통 — 하나라도 어기면 해당 시행 무효)

1. **봉인**: 전 문항 SHA 해시 분할 dev/holdout, holdout은 판정일까지 봉인. 열람=소각·재생성.
   dev↔holdout 갭 >5pp = 암기 신호로 자동 무효. 채점기 코드도 문항과 함께 봉인.
2. **환경**: 단일 소비자 PC(현 RTX 5080 박스급). 로컬 문항은 **네트워크 물리 차단**으로 시행
   (웹 티어 문항만 명시적 예외). 콜드부트 재현: 클린 재기동 후 핵심 수치 재현(±노이즈 범위).
3. **No-LLM 감사**: 시행 중 외부 모델 호출 0 — 프로세스·네트워크 로그 전수 보관.
4. **정직성 동시 조건 (전 문항 오버레이)**: 답의 접지 영수증을 실소스와 전수 대조.
   **fabrication 단 1건 발견 = 해당 티어 전체 FAIL.** 모름/저신뢰는 마킹하면 무벌점 —
   벌하는 것은 침묵이 아니라 조작이다.
5. **지속성 프레임**: 판정 주간(7일) 무운영자 연속 가동, 워치독 자동재기동 ≤3회, no-reset.
6. **재현성**: 티어 판정 수치는 상이한 날 2회 시행 재현으로만 확정.

## 판정식

```
성공       = Tier A 6/6                         (+ 시행규칙 무위반)
완전성공   = Tier A 6/6  AND  Tier B 6/6  AND  Tier C ≥1
```

중간 이정표: A 6/6 + B ≥3 = "완전성공 후보 단계" (대외 주장 금지, 내부 표기만).

## 의도적 제외와 이유 (정직 기록)

- **페라리 1:8 자율 조립** (Metaculus ②): 물리 액추에이터는 현 차터 시대 범위 밖. SPLATRA
  가상 신체가 성숙하면 v2에서 재론.
- **MMLU 평균 90% / APPS 90%**: 남의 시험지의 능력 축 문항. **참조 지표로 추적만** 하고
  성공 기준으로 삼지 않는다(봉인 3벤치는 북극성 참조용으로 유지). 단 B2가 그 벽의 우리식
  정면 돌파 문항이므로 회피가 아니다.

## 구축 순서 (배터리 자체의 로드맵)

1. A3·A5는 기존 하니스 확장으로 즉시 시행 가능 → 첫 봉인 시행
2. A1 강화판(500건·감쇠 곡선), A4 봉인 시나리오셋, A6 대화 배터리 — 생성기 제작
3. A2·B4·B5·B6 — 저널 기반 문항 자동생성기 + 제3자 심판 프로토콜 문서
4. B1·B2 — E9 결과에 따라 계단 설정(오늘 밤 판정이 B2의 출발점을 정한다)
5. C는 각자 독립 원정으로 — C2(몬테주마)와 C6(자율 성장)이 상대적으로 먼저 도전 가능

**시행 전 마지막 규칙**: 이 문서 자체가 v1 봉인본이다. 임계값을 낮추는 개정은 사유·날짜와
함께 운영자 서명으로만 가능하며, 개정 이력은 삭제하지 않는다.

# ATANOR 총 실행 계획 (2026-07-16, 사장님 지시 통합)

> 통합 대상: 3단 정신(R1~R5, `ATANOR_three_tier_mind.md`) + ATANOR Index(`ATANOR_index_design.md`)
> + 영어-only(라이브) + 웹 6/7. 원칙: measure-don't-claim, 게이트 통과 없이 다음 단계 없음, 회귀 금지.

## 실행 순서 (의존성 순)

### Phase 1 — 사람처럼 생각의 뼈대: R1 티어 자각 + R2 캐스케이드 ★최우선
라이브로 실증된 갭("web_search:true인데 로컬 약답 'Korea is a region'에서 멈춤")의 직접 수리.
- **R1 `capability_tier.py`**: 인터넷 도달성 + PROPHETA 팩 존재 감지 → `LOCAL_BASE / LOCAL_EXPERT / SAGE`
  전역 상태. 모든 답 메타에 `knowledge_tier`, 티어별 헤지 표면(오프라인="아마 X일 겁니다"…).
- **R2 답변 캐스케이드**: 뇌형 그래프(T1, 인식사다리) → 팩(T2) → 확신 낮으면 웹 팬아웃(T3, 출처).
  낮은 티어 추측은 높은 티어 증거로 교체 + 교체 표시. 작화 0 불변식 유지.
- **게이트**: 20문 티어 배터리(오프라인 시뮬 포함) green + "Seoul" 케이스가 채팅 end-to-end로 수리
  + 기존 웹 배터리 6/7·뇌형 33테스트·ECE 무회귀.
- 규모: 1~2세션.

### Phase 2 — R3: 채팅이 PROPHETA를 읽게 (T2 배선)
- answer_bridge/캐스케이드가 world_pack_full(141.7M)을 kg_triples와 함께 온디맨드 조회
  (뇌형 그래프서 검증된 store_lookup 패턴 재사용). 팩 자동 감지 = R1의 LOCAL_EXPERT 승격 조건.
- **게이트**: 전/후 커버리지 델타 실측(지식 배터리), 채팅 지연 예산 내(<1s 추가).
- 규모: ~1세션.

### Phase 3 — ATANOR Index V0 (~10GB, 디스크 제약 내)
- 패시지 685k → **EN 위키 전 문서 리드 ~6.9M + Wiktionary 정의 + Simple 전문**.
  디스크-백 역색인(memmap 포스팅) + BM25 + referent resonance 재랭킹.
- 검색 순서 역전: **자체 인덱스 우선 → 미스 시 외부 팬아웃**(오늘 만든 것이 폴백으로).
- **게이트**: 웹 배터리 6/7을 **외부 엔진 0으로** 재현(±1). 미달 시 정직 보고 후 하이브리드 유지.
- 규모: 2~3세션(수확 수 시간 포함).

### Phase 4 — R4: 현자 심화
- 동명이인: 다수 페이지 교차 투표(생몰·직업 일치)로 지배 지시대상 선택 — Einstein 케이스.
- 심층 리서치: 다단계 질문 → decomposer 분해 → 하위질문별 팬아웃 → 뼈+살 종합.
- **상시 학습 루프**: 웹으로 답한 사실 → web_fact_memory → 격리 → 합의 승격 → **T2가 자람**
  (쓸수록 오프라인 전문가가 똑똑해짐 = 사람처럼).
- **게이트**: 동명이인 10문 + 다단계 5문 배터리, 승격된 사실 수 실측.
- 규모: 2~3세션.

### Phase 5 — Ring 1 풀 + Ring 2 (사장님 의존)
- **Ring 1 풀(1~2TB)**: Common Crawl 서브셋 + StackExchange + 도메인 신뢰티어. **새 디스크 필요.**
- **Ring 2**: ATANOR Browser 증류 → 인덱스 인제스트(기존 합의·PII 파이프) + 클릭·체류 신호(행위레인
  로컬, 공유는 익명 집계) → **학습 랭커 v0 (진짜 데이터)** — 합성 전이벽의 해독제.
- 게이트: 인덱스 규모/커버리지 실측, 랭커는 홀드아웃 클릭 예측.
